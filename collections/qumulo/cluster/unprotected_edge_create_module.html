qumulo.cluster.unprotected_edge_create module – Form a single-node unprotected edge from an unconfigured Qumulo node

Note

This module is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.unprotected_edge_create.

New in qumulo.cluster 0.1.0

  • Synopsis

  • Attributes

  • Notes

  • Examples

  • Return Values

Synopsis

  • Forms an unprotected edge, a single-node cluster, from the node at api_host when that node is UNCONFIGURED, and returns the new cluster’s UUID.

  • The node is identified by api_host, and the cluster it forms by cluster_name.

  • Every formation gives the cluster a new UUID, which the request cannot choose (G-UUID).

  • A node that is already ACTIVE in a cluster named cluster_name is left as it is, and the module reports no change. When expected_cluster_uuid is set, that cluster must also have that UUID, or the module fails before any credentials are sent.

  • A node that is ACTIVE in a cluster with another name fails the module.

  • With wait=true, the module waits until the node is ACTIVE, a login as admin succeeds, and the root directory can be read.

  • The request that forms the cluster needs no login. When neither api_password nor api_token is set, api_password is admin_password.

Parameters

Parameter

Comments

admin_password

string / required

The password the new cluster’s admin user gets. It cannot be read back.

api_host

string / required

Address or name of the Qumulo cluster’s REST API.

An IPv6 address is given bare, as fd00::5; the URL puts it in brackets.

If not set, the value of the QUMULO_API_HOST environment variable is used.

api_password

string

Password of api_username.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_PASSWORD environment variable is used.

api_port

integer

TCP port of the REST API.

If not set, the value of the QUMULO_API_PORT environment variable is used.

Default: 8000

api_token

string

An access token, sent in place of logging in.

An access token is bound to one cluster and does not survive a rebuild.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_TOKEN environment variable is used.

api_username

string

User that logs in with api_password.

If not set, the value of the QUMULO_API_USERNAME environment variable is used.

Default: "admin"

ca_path

path

PEM file of the certificate authority that signed the cluster’s certificate.

On Python 3.13 and later this must be a CA certificate, with basic constraints.

A bare self-signed leaf certificate cannot be pinned here on Python 3.13 and later; such a cluster is reached only with validate_certs=false.

If not set, the value of the QUMULO_CA_PATH environment variable is used.

cluster_name

string / required

The new cluster’s name, 2 to 15 letters, digits or hyphens, starting and ending with a letter or digit.

A name outside these rules fails before any request is sent.

eula_accepted

boolean / required

Accept Qumulo’s end user license agreement, which forming a cluster needs. Anything but true fails before any request is sent.

Choices:

  • false

  • true

expected_cluster_uuid

string

The UUID the cluster at api_host must have.

Before the first credentials are sent, the module reads the cluster’s UUID from GET /v1/node/state, which needs no login, and fails when it differs, so that no credentials are sent to the wrong cluster. On a mismatch the task fails with live_cluster_uuid and expected_cluster_uuid in its result.

An empty value disables this identity guard, and a module that logs in warns.

If not set, the value of the QUMULO_EXPECTED_CLUSTER_UUID environment variable is used.

request_timeout

integer

Seconds to wait for one HTTP response.

If not set, the value of the QUMULO_REQUEST_TIMEOUT environment variable is used.

Default: 60

retry_timeout

integer

Seconds to keep retrying a request that is safe to resend, after a lost connection or an HTTP 502, 503 or 504.

If not set, the value of the QUMULO_RETRY_TIMEOUT environment variable is used.

Default: 300

validate_certs

boolean

Verify the cluster’s TLS certificate.

If not set, the value of the QUMULO_VALIDATE_CERTS environment variable is used.

Choices:

  • false

  • true ← (default)

wait

boolean

Wait until the new cluster is ready. With false, the module returns once the cluster has accepted the request.

Choices:

  • false

  • true ← (default)

wait_timeout

integer

Seconds to wait for the node to become ACTIVE and serve its file system, including while its REST API does not answer.

Default: 900

Attributes

Attribute

Support

Description

action_group

Action group: qumulo.cluster.qumulo

Use group/qumulo.cluster.qumulo in module_defaults to set the connection options for this module.

check_mode

Support: full

Predicts the formation; the new UUID is known only once it has happened.

Can run in check mode and return a changed status prediction without modifying the cluster.

diff_mode

Support: full

The diff shows the node’s state before, UNCONFIGURED, and the cluster the task forms, with its name and ACTIVE, in check mode too.

Will return details on what has changed, or would change in check mode, when in diff mode.

idempotent

Support: partial

Forms a cluster only from an UNCONFIGURED node, and each formation mints a new UUID.

When run twice in a row outside check mode with the same arguments, the second run reports no change.

This assumes that nothing else changed the cluster in between.

Notes

Note

  • API: GET /v1/node/state and GET /v1/cluster/settings, both without login; POST /v2/cluster/unprotected-edge/create without login; with wait, GET /v1/files/%2F/info/attributes.

  • The create request is never sent twice. With wait, if its connection is lost, the module waits for the node, which then shows whether it formed; without wait, it fails with maybe_applied.

  • Registers: G-UUID.

Examples

# These tasks carry no connection options. Set them once for the play with module_defaults for
# group/qumulo.cluster.qumulo, or in the QUMULO_* environment variables.
- name: Check that the reinstalled node is unconfigured and would be formed
  qumulo.cluster.unprotected_edge_create:
    cluster_name: "{{ qumulo_cluster_name }}"
    admin_password: "{{ qumulo_api_password }}"
    eula_accepted: true
  check_mode: true
  diff: true
  register: edge_preview

- name: On a rebuild, stop if the node already holds a cluster
  ansible.builtin.assert:
    that: edge_preview.unprotected_edge.state == 'UNCONFIGURED'
    fail_msg: "{{ qumulo_api_host }} is already ACTIVE as {{ edge_preview.unprotected_edge.cluster_id }}"

- name: Form the edge on a reinstalled node, then record its new UUID
  # Every formation gives the cluster a new UUID (G-UUID). A node already ACTIVE under this name is left as it is.
  # What is keyed on the previous UUID, such as the license, the hub's portal record and the Nexus registration, is
  # then replayed for the new one; the edge_rebuild role does that.
  qumulo.cluster.unprotected_edge_create:
    cluster_name: "{{ qumulo_cluster_name }}"
    admin_password: "{{ qumulo_api_password }}"
    eula_accepted: true
  register: formed

- name: Point the identity guard at the new cluster
  ansible.builtin.set_fact:
    qumulo_cluster_uuid: "{{ formed.unprotected_edge.cluster_id }}"

- name: Form the edge, or confirm that the ACTIVE node is the cluster whose UUID the inventory records
  # An ACTIVE node with another UUID fails before any credentials are sent.
  qumulo.cluster.unprotected_edge_create:
    cluster_name: "{{ qumulo_cluster_name }}"
    admin_password: "{{ qumulo_api_password }}"
    eula_accepted: true
    expected_cluster_uuid: "{{ qumulo_cluster_uuid }}"

- name: Start forming the edge and return when the node has accepted the request
  # With wait false the result still shows the node as UNCONFIGURED, with no UUID.
  qumulo.cluster.unprotected_edge_create:
    cluster_name: "{{ qumulo_cluster_name }}"
    admin_password: "{{ qumulo_api_password }}"
    eula_accepted: true
    wait: false

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

expected_cluster_uuid

string

expected_cluster_uuid, as the module compared it.

Returned: on that failure

Sample: "1b2c33f0-5c3a-4c56-9d2e-3f8c1b0a7e11"

live_cluster_uuid

string

The UUID of the ACTIVE cluster at api_host, when it differs from expected_cluster_uuid.

Returned: on that failure

Sample: "6f1c2c1e-5c3a-4c56-9d2e-3f8c1b0a7e11"

maybe_applied

boolean

True when the create was sent and its connection was lost, and either wait was false or the wait did not show that the node formed.

Returned: on such a failure

Sample: true

unprotected_edge

dictionary

The cluster after the task. In check mode on an UNCONFIGURED node, the cluster the task would form, with no UUID yet.

With wait=false, the request as sent, with no UUID.

Returned: always

Sample: {"cluster_id": "1b2c33f0-5c3a-4c56-9d2e-3f8c1b0a7e11", "cluster_name": "edge01", "state": "ACTIVE"}

cluster_id

string

The cluster’s UUID; null when it is not known yet.

Returned: success

cluster_name

string

The cluster’s name.

Returned: success

state

string

The node’s state, such as ACTIVE, or UNCONFIGURED in check mode and with wait=false.

Returned: success
