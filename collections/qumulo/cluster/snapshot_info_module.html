qumulo.cluster.snapshot_info module – Read a Qumulo cluster’s snapshots, snapshot policies, snapshot capacity and lock keys

Note

This module is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.snapshot_info.

New in qumulo.cluster 0.1.0

  • Synopsis

  • Parameters

  • Attributes

  • Notes

  • Examples

  • Return Values

Synopsis

  • Gathers the snapshots, snapshot policies, snapshot capacity and lock keys of one cluster, and changes nothing.

  • Each policy comes back in the option shape of qumulo.cluster.snapshot_policy, so it carries its name and no id.

  • Each key comes back in the option shape of qumulo.cluster.security_key, with its id and what uses it.

Parameters

Parameter

Comments

api_host

string / required

Address or name of the Qumulo cluster’s REST API.

An IPv6 address is given bare, as fd00::5; the URL puts it in brackets.

If not set, the value of the QUMULO_API_HOST environment variable is used.

api_password

string

Password of api_username.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_PASSWORD environment variable is used.

api_port

integer

TCP port of the REST API.

If not set, the value of the QUMULO_API_PORT environment variable is used.

Default: 8000

api_token

string

An access token, sent in place of logging in.

An access token is bound to one cluster and does not survive a rebuild.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_TOKEN environment variable is used.

api_username

string

User that logs in with api_password.

If not set, the value of the QUMULO_API_USERNAME environment variable is used.

Default: "admin"

ca_path

path

PEM file of the certificate authority that signed the cluster’s certificate.

On Python 3.13 and later this must be a CA certificate, with basic constraints.

A bare self-signed leaf certificate cannot be pinned here on Python 3.13 and later; such a cluster is reached only with validate_certs=false.

If not set, the value of the QUMULO_CA_PATH environment variable is used.

expected_cluster_uuid

string

The UUID the cluster at api_host must have.

Before the first credentials are sent, the module reads the cluster’s UUID from GET /v1/node/state, which needs no login, and fails when it differs, so that no credentials are sent to the wrong cluster. On a mismatch the task fails with live_cluster_uuid and expected_cluster_uuid in its result.

An empty value disables this identity guard, and a module that logs in warns.

If not set, the value of the QUMULO_EXPECTED_CLUSTER_UUID environment variable is used.

gather_subset

list / elements=string

The subsets of facts to gather. all gathers every subset.

snapshots is every snapshot, policies every snapshot policy, capacity the space the snapshots use, and security_keys every key in the file system key store with what uses it.

When the API user may not read the key store, security_keys is listed in unavailable_subsets and the other subsets are gathered. A key deleted while the keys are read is left out.

Choices:

  • "all" ← (default)

  • "snapshots"

  • "policies"

  • "capacity"

  • "security_keys"

Default: ["all"]

request_timeout

integer

Seconds to wait for one HTTP response.

If not set, the value of the QUMULO_REQUEST_TIMEOUT environment variable is used.

Default: 60

retry_timeout

integer

Seconds to keep retrying a request that is safe to resend, after a lost connection or an HTTP 502, 503 or 504.

If not set, the value of the QUMULO_RETRY_TIMEOUT environment variable is used.

Default: 300

validate_certs

boolean

Verify the cluster’s TLS certificate.

If not set, the value of the QUMULO_VALIDATE_CERTS environment variable is used.

Choices:

  • false

  • true ← (default)

Notes

Note

  • API: snapshots GET /v4/snapshots/status/; policies GET /v3/snapshots/policies/status/; capacity GET /v1/snapshots/total-used-capacity; security_keys GET /v1/file-system/security/keys/ and GET /v1/file-system/security/keys/{id}/usages for each key.

Examples

# These tasks carry no connection options. Set them once for the play with module_defaults for
# group/qumulo.cluster.qumulo, or in the QUMULO_* environment variables.
- name: Read the snapshots, policies, capacity and lock keys
  qumulo.cluster.snapshot_info:
  register: snapshots

- name: List the snapshots that are not being deleted
  ansible.builtin.debug:
    msg: "{{ snapshots.snapshots.snapshots | rejectattr('in_delete') | map(attribute='name') | list }}"

- name: List the snapshots of the project tree
  qumulo.cluster.snapshot_info:
    gather_subset: [snapshots]
  register: project_snapshots

- name: Show the names of the project tree's snapshots
  ansible.builtin.debug:
    msg: "{{ project_snapshots.snapshots.snapshots | selectattr('path', 'equalto', '/data/projects') | map(attribute='name') | list }}"

- name: Read the snapshot policies
  qumulo.cluster.snapshot_info:
    gather_subset: [policies]
  register: policy_facts

- name: List the policies that are switched off
  ansible.builtin.debug:
    msg: "{{ policy_facts.snapshots.policies | rejectattr('enabled') | map(attribute='policy_name') | list }}"

- name: Read how much space the snapshots use
  qumulo.cluster.snapshot_info:
    gather_subset: [capacity]
  register: snapshot_capacity

- name: Show the space deleting every snapshot would free
  ansible.builtin.debug:
    msg: "{{ snapshot_capacity.snapshots.capacity.used_bytes }} bytes"

- name: Read the lock keys and what uses each
  qumulo.cluster.snapshot_info:
    gather_subset: [security_keys]
  register: key_facts

- name: List the ids of the snapshots the legal-hold key locks
  ansible.builtin.debug:
    msg: >-
      {{ key_facts.snapshots.security_keys | selectattr('name', 'equalto', 'legal-hold') | map(attribute='usages') | flatten
         | selectattr('type', 'equalto', 'snapshot') | map(attribute='id') | list }}
