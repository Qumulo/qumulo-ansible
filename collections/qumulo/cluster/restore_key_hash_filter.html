qumulo.cluster.restore_key_hash filter – The digest that names a relationship’s restore record and restore stamp

Note

This filter plugin is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.restore_key_hash.

New in qumulo.cluster 0.1.0

  • Synopsis

  • Input

  • Examples

  • Return Value

Synopsis

  • The SHA-256 hex digest of a replication relationship’s normalized key, written as the three lines <source path>, <target cluster UUID> and <target path>, joined by newlines, with each path without its trailing slash (/ stays /) and the UUID in lower case.

  • The restore record under <artifact dir>/<host>/restore/ is named <digest>.yml, and its restore stamp done-<digest>.yml.

  • The target host’s name is not hashed.

Input

This describes the input of the filter, the value before | qumulo.cluster.restore_key_hash.

Parameter

Comments

Input

dictionary / required

The key.

source_path

string / required

The relationship’s source path on the edge.

target_cluster_uuid

string / required

The target cluster’s UUID.

target_host

string

The target’s inventory host name, which the record holds but the digest leaves out.

target_path

string / required

The relationship’s target path on the target cluster.

Examples

- name: Name the relationship's restore record
  vars:
    artifact_dir: "{{ ansible_inventory_sources | qumulo.cluster.artifact_dir(inventory_file | default('')) }}"
    hub_uuid: 7d4a2e10-3c8b-4f5a-9b6e-1a2b3c4d5e6f
  ansible.builtin.debug:
    msg: >-
      {{ artifact_dir }}/{{ inventory_hostname }}/restore/{{
         {'source_path': '/projects', 'target_cluster_uuid': hub_uuid, 'target_path': '/replicas/edge01'}
         | qumulo.cluster.restore_key_hash }}.yml

- name: Name the relationship's restore stamp
  # Trailing slashes are dropped, so this names the same stamp as /projects and /replicas/edge01.
  vars:
    artifact_dir: "{{ ansible_inventory_sources | qumulo.cluster.artifact_dir(inventory_file | default('')) }}"
    hub_uuid: 7d4a2e10-3c8b-4f5a-9b6e-1a2b3c4d5e6f
  ansible.builtin.debug:
    msg: >-
      {{ artifact_dir }}/{{ inventory_hostname }}/restore/done-{{
         {'source_path': '/projects/', 'target_cluster_uuid': hub_uuid, 'target_path': '/replicas/edge01/'}
         | qumulo.cluster.restore_key_hash }}.yml

- name: Check whether the relationship's restore stamp exists
  vars:
    artifact_dir: "{{ ansible_inventory_sources | qumulo.cluster.artifact_dir(inventory_file | default('')) }}"
    hub_uuid: 7d4a2e10-3c8b-4f5a-9b6e-1a2b3c4d5e6f
  ansible.builtin.stat:
    path: >-
      {{ artifact_dir }}/{{ inventory_hostname }}/restore/done-{{
         {'source_path': '/projects', 'target_cluster_uuid': hub_uuid, 'target_path': '/replicas/edge01'}
         | qumulo.cluster.restore_key_hash }}.yml
  delegate_to: localhost
  register: restore_stamp

Return Value

Key

Description

Return value

string

The digest, 64 lower-case hex digits.

Returned: always

Sample: "c6f21a2d2f429154980c601dcefa44cce45d276f639aff197d40598dc1ef34dc"
