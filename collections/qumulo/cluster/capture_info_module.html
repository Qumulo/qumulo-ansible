qumulo.cluster.capture_info module – Read a Qumulo cluster’s configuration as the inventory variables that declare it

Note

This module is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.capture_info.

New in qumulo.cluster 0.1.0

Synopsis

  • Reads every setting the collection’s modules write and the cluster reads back, and returns it as the qumulo_* variables of the cluster_baseline role, in the shape the role passes to those modules. A check run of the role from the returned variables changes nothing.

  • Changes nothing on the cluster. playbooks/capture.yml writes the result to a host_vars file.

  • Values are canonical and lists sorted, so two reads of an unchanged cluster return the same variables.

  • No secret is returned. The one secret read, the keytab’s keys in the kerberos area, is registered for masking and dropped. Each secret the inventory must supply to manage an area, such as a local user’s password, the certificate’s private key, the AD join password or a Nexus join key, is named in capture.supply instead.

  • The cluster’s UUID is always returned; the license’s own UUID and any earlier UUID never are.

  • Fails on a node that belongs to no cluster yet (state UNCONFIGURED), which has nothing to capture.

Parameters

Parameter

Comments

api_host

string / required

Address or name of the Qumulo cluster’s REST API.

An IPv6 address is given bare, as fd00::5; the URL puts it in brackets.

If not set, the value of the QUMULO_API_HOST environment variable is used.

api_password

string

Password of api_username.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_PASSWORD environment variable is used.

api_port

integer

TCP port of the REST API.

If not set, the value of the QUMULO_API_PORT environment variable is used.

Default: 8000

api_token

string

An access token, sent in place of logging in.

An access token is bound to one cluster and does not survive a rebuild.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_TOKEN environment variable is used.

api_username

string

User that logs in with api_password.

If not set, the value of the QUMULO_API_USERNAME environment variable is used.

Default: "admin"

ca_path

path

PEM file of the certificate authority that signed the cluster’s certificate.

On Python 3.13 and later this must be a CA certificate, with basic constraints.

A bare self-signed leaf certificate cannot be pinned here on Python 3.13 and later; such a cluster is reached only with validate_certs=false.

If not set, the value of the QUMULO_CA_PATH environment variable is used.

expected_cluster_uuid

string

The UUID the cluster at api_host must have.

Before the first credentials are sent, the module reads the cluster’s UUID from GET /v1/node/state, which needs no login, and fails when it differs, so that no credentials are sent to the wrong cluster. On a mismatch the task fails with live_cluster_uuid and expected_cluster_uuid in its result.

An empty value disables this identity guard, and a module that logs in warns.

If not set, the value of the QUMULO_EXPECTED_CLUSTER_UUID environment variable is used.

gather_subset

list / elements=string

The areas to read, named as the cluster_baseline role names them. all reads every area.

cluster the name.

filesystem the file system settings.

web_ui the Web UI’s banner and timeout.

network the network document. With the tenants area, a tenant’s networks are written under its entry, each with vlan_id when a frontend VLAN carries it and mtu when that VLAN sets one, and managed_interfaces lists neither the VLANs that carry only tenant networks nor tenant networks on the frontend bond. A network on the backend bond, or one no tenant holds, stays in qumulo_network. Without the tenants area, or on a cluster that does not offer the tenant list, every network is written in qumulo_network; on a cluster with two or more tenants, each network a tenant holds off the backend bond carries tenant by name.

dns the DNS settings, the lookup overrides and the authoritative DNS settings.

time the time settings.

ssl the cipher suites. The certificate and its key are not returned (G-SSL-READBACK); capture.supply names them.

monitoring cloud monitoring and the Nexus connection.

audit the audit log destinations.

capacity the clamp, the eviction threshold and the license. The license is required when one is active for the cluster’s UUID, and none on an unprotected edge that holds none.

local_groups, local_users, ad and roles the identities.

kerberos the Kerberos settings. A keytab the cluster holds is never returned; a supply line names its principals.

saml the SAML settings once SAML is set up, the IdP certificate included, which is public.

identity_mappings the user-defined mappings, as qumulo_user_defined_mappings. qumulo_identity_attributes is never returned, since the cluster cannot list it (G-ID-ATTRIBUTES).

portal the spoke portal.

directories each directory that a share, an export, a quota, a snapshot policy, an S3 bucket, the S3 base path or a replication target names, and each directory above one, the root included. A directory carries its ACL in place of its mode when the mode cannot express the ACL.

smb and nfs the settings, the shares or exports, and whether the factory share and export are present in tenant 1. With the tenants area, each share or export is written under its tenant’s entry, and one identical in two or more tenants once in qumulo_smb_shares or qumulo_nfs_exports, with tenants set to all when it is in every tenant, else to its tenants’ names, sorted. The factory Files share and / export stay under tenant 1 and are never merged. Without the tenants area, or on a cluster that does not offer the tenant list, on a cluster with one tenant they are written flat, with no tenant, and the tenant’s own settings are noted in capture.left_out; on a cluster with two or more, qumulo_smb_shares and qumulo_nfs_exports are written empty, and each tenant’s shares, exports and settings are noted in capture.left_out.

tenants qumulo_tenants, every tenant by name, sorted, with its six services, and with what the network, smb and nfs areas read of it, its networks, [] for none, its smb_settings and nfs_settings, inherit without settings of its own, else the full record, and its smb_shares and nfs_exports, each left out when it has none. Tenant 1 renamed carries previous_name Default. A cluster without tenant 1 whose networking the host manages, with no managed interfaces and only HOST networks, gets previous_name Default on the one tenant that holds a network, and no entry Default, when the network, smb and nfs areas are read, every network has a tenant, no tenant is named Default, and that tenant has no / export that the capture leaves out. A rebuild from the capture then renames the Default the new edge forms with to that tenant. In that case smb_files_share in qumulo_factory_defaults is present in place of absent when the capture writes a share named Files for that tenant, in any letter case, and nfs_root_export when it writes that tenant’s export at /. Any other cluster without tenant 1 gets an entry Default with state absent, unless another tenant is named Default, or, with no network that no tenant holds, a network on the backend bond stays in qumulo_network.frontend_networks or leave_out names network, smb or nfs. The tenant 1 note in capture.left_out gives the reason for the form it writes. On a cluster whose protection type marks it as cloud, the services are left out.

s3 the S3 server settings, buckets, bucket policies and access keys, without their secrets.

ftp the FTP server settings, as qumulo_ftp_settings. An anonymous user that names a deleted local user, or that is not a local user, is left out, and capture.left_out says so.

quotas the directory quotas.

snapshots the snapshot policies.

replication the relationships this cluster is the source of, and the address each source records for a target, for the target’s host.

inventory_clusters

dictionary

The inventory’s clusters, each UUID mapped to its inventory host.

A spoke portal’s hub and a replication relationship’s target are declared by their inventory host. One whose cluster is missing here is left out, and capture.left_out says so.

Default: {}

leave_out

list / elements=string

Areas, or parts of an area, that another tool owns and that are not read, such as those qumulo_terraform_owned_areas gives to Terraform.

Each that applies is noted in capture.left_out: an area named here and in gather_subset, a part once its area is read, and audit.cloudwatch once for each CloudWatch destination it leaves out.

An area is any choice of gather_subset other than all.

network.floating_ips reads the network document without its floating IP ranges.

dns.fqdn reads the authoritative DNS settings without the name and whether the server answers.

audit.cloudwatch reads the audit log destinations without the CloudWatch ones.

tenants writes no qumulo_tenants, and the network, smb and nfs areas write the form gather_subset describes without it.

Any other name fails before a request is sent.

Default: []

request_timeout

integer

Seconds to wait for one HTTP response.

If not set, the value of the QUMULO_REQUEST_TIMEOUT environment variable is used.

Default: 60

retry_timeout

integer

Seconds to keep retrying a request that is safe to resend, after a lost connection or an HTTP 502, 503 or 504.

If not set, the value of the QUMULO_RETRY_TIMEOUT environment variable is used.

Default: 300

validate_certs

boolean

Verify the cluster’s TLS certificate.

If not set, the value of the QUMULO_VALIDATE_CERTS environment variable is used.

Choices:

  • false

  • true ← (default)

Notes

Note

  • API: cluster GET /v1/cluster/settings; filesystem GET /v1/file-system/settings/permissions, /atime and /notify; web_ui GET /v1/web-ui/settings; network GET /v3/network; dns GET /v1/dns/configs/system, /v1/dns/lookup-override-config and /v1/authoritative-dns/settings; time GET /v2/time/settings; ssl GET /v2/cluster/settings/ssl/ciphers and the certificate served at api_host; monitoring GET /v1/support/settings, /v1/nexus/connection and /v1/nexus/registration; audit GET /v2/audit/destinations/; capacity GET /v1/capacity/clamp, /v1/portal/spokes/eviction-settings and /v1/license/status, and without a license the product type as qumulo.cluster.cluster_info reads it; local_groups, local_users and roles as qumulo.cluster.identity_info reads them; ad GET /v1/ad/status and /v1/ad/monitor; kerberos GET /v1/auth/kerberos-settings and /v1/auth/kerberos-keytab, whose keys are read and never returned, and which needs PRIVILEGE_KERBEROS_KEYTAB_READ; without it the area writes the setting and notes in capture.left_out that the keytab could not be read; saml GET /v1/saml/settings; identity_mappings GET /v1/auth/user-defined-mappings/; portal GET /v2/portal/spokes/ and /v2/portal/hubs/; directories GET /v1/files/{ref}/info/attributes and /v2/files/{ref}/info/acl and POST /v1/files/{ref}/info/acl/explain-set-mode, a preview that changes nothing, for each directory; smb GET /v1/smb/settings, /v3/smb/shares/ and /v1/multitenancy/smb/settings/; nfs GET /v2/nfs/settings, /v3/nfs/exports/ and /v1/multitenancy/nfs/settings/; network, smb, nfs and tenants GET /v1/multitenancy/tenants/, which needs PRIVILEGE_TENANT_READ, so that without it the capture of any of the four areas fails; tenants GET /v1/cluster/protection/status; s3 GET /v1/s3/settings, /v1/s3/buckets/ and each bucket’s /v1/s3/buckets/{name}/policy, and /v1/s3/access-keys/; ftp GET /v0/ftp/settings; quotas GET /v1/files/quotas/status/; snapshots GET /v3/snapshots/policies/status/; replication GET /v2/replication/source-relationships/status/ and /v2/replication/target-relationships/status/.

  • Qumulo marks the /v3/smb/shares/ and /v3/nfs/exports/ routes the smb and nfs areas read as preview in Qumulo Core 7.10.3 and 7.11.0; a later Qumulo Core release may change them.

  • The network, smb, nfs and tenants areas resolve tenants through the multitenancy REST API, which Qumulo marks as preview; a later Qumulo Core release may change it.

  • Noted in capture.left_out: a cloud cluster’s tenant services, since no cloud cluster accepts a tenant write (G-TENANT-CLOUD); a missing tenant 1, written as the rename of Default to the tenant that holds the network on networking the host manages, else as Default absent, and not written when another tenant is named Default or a replay could not delete it; a tenant whose identity configuration differs from tenant 1’s, written in full but for its identity; with the tenants area, or on a cluster with two or more tenants, a VLAN that carries networks of two tenants, or of a tenant and of no tenant; and, on a cluster with two or more tenants, a backend network a tenant holds (G-TENANT-BACKEND), and a network no tenant holds.

  • The cluster lists no identity that has attributes, so qumulo_identity_attributes is never captured (G-ID-ATTRIBUTES).

  • The cluster returns neither its certificate nor the key (G-SSL-READBACK), nor the configured domain controllers of a domain joined before the last AD operation (G-AD-DCS), nor a Nexus join key (G-NEXUS-KEY), nor the secret of an S3 access key (G-S3-KEY), which capture.supply names by the key’s id. A cluster other than an unprotected edge without an active license for its UUID needs a license document (G-LICENSE). An export mapped to a user or group that no longer exists is left out (G-MAPTO).

  • Each side of a portal records only the other side’s addresses (G-PORTAL-HOSTS), and a replication source the address it reaches the target at, so capture.peer_values gives them for the peer’s host, and playbooks/capture.yml writes them as that host’s qumulo_portal_hosts or qumulo_replication_address when every record of them agrees and comes from a live portal or relationship.

  • A directory, quota, snapshot policy or S3 bucket in a spoke root is the hub’s data and is left out. A replication target directory is declared by its path alone, and what lies inside it is left out.

  • An area this cluster does not offer is listed in unavailable_subsets and in capture.left_out.

  • Registers: G-AD-DCS, G-ID-ATTRIBUTES, G-LICENSE, G-MAPTO, G-NEXUS-KEY, G-PORTAL-HOSTS, G-S3-KEY, G-SSL-READBACK, G-TENANT-BACKEND, G-TENANT-CLOUD.

Examples

# These tasks carry no connection options. Set them once for the play with module_defaults for
# group/qumulo.cluster.qumulo, or in the QUMULO_* environment variables.
- name: Read the cluster's whole configuration
  qumulo.cluster.capture_info:
  register: captured

- name: Read only the DNS and time settings
  qumulo.cluster.capture_info:
    gather_subset: [dns, time]
  register: network_services

# Each tenant's networks, SMB and NFS settings, shares and exports go under its entry in qumulo_tenants.
- name: Read the tenants with their networks, settings, shares and exports
  qumulo.cluster.capture_info:
    gather_subset: [network, smb, nfs, tenants]
  register: tenancy

# On a cluster with two or more tenants, this writes each network a tenant holds flat with its tenant by name, and notes
# each tenant's shares, exports and settings in left_out, since only the tenants area writes them there.
- name: Read a cluster whose tenants Terraform owns
  qumulo.cluster.capture_info:
    leave_out: [tenants]
  register: captured

# Without qumulo_terraform_owned_areas, the cluster_baseline role gives Terraform the floating IP ranges of a cluster whose
# qumulo_managed_by is terraform_provider, unless its qumulo_cluster_kind is edge or baremetal, and this default does the same.
- name: Read a Terraform-managed cluster without the areas Terraform owns
  qumulo.cluster.capture_info:
    leave_out: >-
      {{ qumulo_terraform_owned_areas
         | default(['network.floating_ips'] if qumulo_managed_by | default('none') == 'terraform_provider'
                   and qumulo_cluster_kind | default(none) not in ['edge', 'baremetal'] else []) }}
  register: captured

- name: Read a cluster without its floating IP ranges, the authoritative DNS name and the CloudWatch audit destinations
  qumulo.cluster.capture_info:
    leave_out: [network.floating_ips, dns.fqdn, audit.cloudwatch]
  register: captured

# A portal's hub and a replication target are named by inventory host, so map each cluster UUID to its host. The keys are
# cluster UUIDs and the values are inventory hosts. A host with no UUID yet, one awaiting adoption, has no entry.
- name: Read a cluster that is a spoke or a replication source, naming its peers by inventory host
  qumulo.cluster.capture_info:
    inventory_clusters:
      6f1c2c1e-5c3a-4c56-9d2e-3f8c1b0a7e11: hub01
      9533a9e2-e57a-454f-8aa0-9c77b706b7bd: edge01
  register: captured

- name: List what the capture left out, and the secrets the inventory must supply
  ansible.builtin.debug:
    msg:
      left_out: "{{ captured.capture.left_out }}"
      supply: "{{ captured.capture.supply }}"

- name: Render the capture as a host_vars file whose captured strings Ansible never templates
  qumulo.cluster.host_vars_text:
    variables: "{{ captured.capture.host_vars }}"
    header: Captured from {{ inventory_hostname }}.
    supply: "{{ captured.capture.supply }}"
    left_out: "{{ captured.capture.left_out }}"
  register: rendered
  delegate_to: localhost

- name: Write the capture as the host's variables, readable by its owner only
  ansible.builtin.copy:
    dest: "captures/{{ inventory_hostname }}.yml"
    content: "{{ rendered.text }}"
    mode: "0600"
  delegate_to: localhost

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

capture

dictionary

What was read.

Returned: always

from_peers

list / elements=string

The variables of this cluster’s own that only its peers record, qumulo_portal_hosts for a cluster in a portal and qumulo_replication_address for a replication target.

Returned: success

Sample: ["qumulo_portal_hosts"]

host_vars

dictionary

The qumulo_* variables, sorted by name, each in the shape the cluster_baseline role takes it, with keys whose value is unset left out. qumulo_cluster_uuid is always there.

No tenant id is returned anywhere; tenants are named.

qumulo_replication_relationships lists the relationships this cluster is the source of, each entry’s settings as qumulo.cluster.replication_relationship takes them and its target named by inventory host.

Returned: success

Sample: {"qumulo_cluster_name": "edge01", "qumulo_cluster_uuid": "6f1c2c1e-5c3a-4c56-9d2e-3f8c1b0a7e11", "qumulo_dns": {"search_domains": ["corp.example.com"], "servers": ["10.0.0.2"]}, "qumulo_factory_defaults": {"nfs_root_export": "absent", "smb_files_share": "present"}, "qumulo_tenants": [{"name": "Default", "networks": [], "nfs_enabled": true, "nfs_settings": "inherit", "replication_enabled": true, "rest_api_enabled": true, "smb_enabled": true, "smb_settings": "inherit", "ssh_enabled": true, "web_ui_enabled": true}]}

left_out

list / elements=dictionary

What was read but is not in capture.host_vars, or is written there in a form its note explains, such as a missing tenant 1 written as Default absent or as the rename of Default, each with what and why, sorted by what.

Returned: success

Sample: [{"what": "the floating IP ranges", "why": "leave_out names network.floating_ips, as Terraform owns them"}]

peer_values

list / elements=dictionary

What this cluster records of another cluster’s own variables, sorted. Each has uuid, the other cluster’s; variable, qumulo_portal_hosts or qumulo_replication_address; value, a list of address and port or one address and port; recorded_by, this cluster’s UUID; and unusable, why the record must not be copied, such as a portal that is not ACCEPTED and ACTIVE, or null.

Returned: success

Sample: [{"recorded_by": "6f1c2c1e-5c3a-4c56-9d2e-3f8c1b0a7e11", "unusable": null, "uuid": "9533a9e2-e57a-454f-8aa0-9c77b706b7bd", "value": [{"address": "10.0.1.20", "port": 3713}], "variable": "qumulo_portal_hosts"}]

replication_targets

list / elements=string

The directory of each replication relationship this cluster is the target of and that has not ENDED, sorted, as the directories area reads them. A clone of this cluster leaves them out.

Returned: success

Sample: ["/replicas/edge01-projects"]

spoke_roots

list / elements=string

The directory of each root of this cluster’s spoke portals, whatever their state, sorted, as the portal area reads them. A clone of this cluster leaves out what lies in them, whose data the hub holds.

Returned: success

Sample: ["/hub-projects"]

supply

list / elements=dictionary

Each secret the inventory must supply to manage an area, with variable and why, sorted by variable.

Returned: success

Sample: [{"variable": "qumulo_ssl.private_key", "why": "the cluster serves a certificate whose SHA-256 is ..."}]

unavailable_subsets

dictionary

Each requested area this cluster could not answer, mapped to the reason.

Returned: when an area was unavailable

Sample: {"portal": "GET /v2/portal/spokes/ failed: HTTP 404 ..."}
