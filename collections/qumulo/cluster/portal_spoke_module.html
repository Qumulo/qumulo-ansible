qumulo.cluster.portal_spoke module – Propose a spoke portal to a hub cluster, or delete it

Note

This module is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.portal_spoke.

New in qumulo.cluster 0.1.0

  • Synopsis

  • Parameters

  • Attributes

  • Notes

  • Examples

  • Return Values

Synopsis

  • Runs on the spoke cluster. A spoke proposes a portal relationship and its root directories; the hub accepts them with qumulo.cluster.portal_hub. The qumulo.cluster.portal_pair role pairs both sides in one play.

  • The portal is identified by the pair of cluster UUIDs, this cluster’s and hub_cluster_uuid, and each root by its spoke root path, never by a server id. A cluster has at most one spoke portal to a given hub cluster.

  • Creating the spoke portal and proposing a root cannot be retried safely, so before either the module checks on this cluster that each new spoke root does not exist yet and that its parent directory does.

  • With state=absent, deletes the spoke portal, which hands its outstanding writes to the hub first.

Parameters

Parameter

Comments

allow_data_loss

boolean

Allow deleting a spoke portal whose hub is DISCONNECTED. The delete is then forced, and spoke writes that the hub has not received are lost.

Without it, deleting a DISCONNECTED spoke portal fails before any request that changes the cluster.

Choices:

  • false ← (default)

  • true

api_host

string / required

Address or name of the Qumulo cluster’s REST API.

An IPv6 address is given bare, as fd00::5; the URL puts it in brackets.

If not set, the value of the QUMULO_API_HOST environment variable is used.

api_password

string

Password of api_username.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_PASSWORD environment variable is used.

api_port

integer

TCP port of the REST API.

If not set, the value of the QUMULO_API_PORT environment variable is used.

Default: 8000

api_token

string

An access token, sent in place of logging in.

An access token is bound to one cluster and does not survive a rebuild.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_TOKEN environment variable is used.

api_username

string

User that logs in with api_password.

If not set, the value of the QUMULO_API_USERNAME environment variable is used.

Default: "admin"

ca_path

path

PEM file of the certificate authority that signed the cluster’s certificate.

On Python 3.13 and later this must be a CA certificate, with basic constraints.

A bare self-signed leaf certificate cannot be pinned here on Python 3.13 and later; such a cluster is reached only with validate_certs=false.

If not set, the value of the QUMULO_CA_PATH environment variable is used.

expected_cluster_uuid

string

The UUID the cluster at api_host must have.

Before the first credentials are sent, the module reads the cluster’s UUID from GET /v1/node/state, which needs no login, and fails when it differs, so that no credentials are sent to the wrong cluster. On a mismatch the task fails with live_cluster_uuid and expected_cluster_uuid in its result.

An empty value disables this identity guard, and a module that logs in warns.

If not set, the value of the QUMULO_EXPECTED_CLUSTER_UUID environment variable is used.

hub_cluster_uuid

string / required

UUID of the hub cluster.

When hub_hosts reach a cluster with another UUID, the module withdraws the proposal it just made and fails.

hub_hosts

list / elements=dictionary

IP addresses of the hub cluster, as this cluster reaches them on the portal port.

Needed to create the spoke portal. Changed in place when they differ, compared in any order.

Never an FQDN. For a cluster with floating IPs, its floating IPs; for a multi-AZ cluster in AWS, its load balancer’s IPs; otherwise its node IPs.

address

string / required

An IP address of the hub.

port

integer

The hub’s portal port.

Default: 3713

request_timeout

integer

Seconds to wait for one HTTP response.

If not set, the value of the QUMULO_REQUEST_TIMEOUT environment variable is used.

Default: 60

retry_timeout

integer

Seconds to keep retrying a request that is safe to resend, after a lost connection or an HTTP 502, 503 or 504.

If not set, the value of the QUMULO_RETRY_TIMEOUT environment variable is used.

Default: 300

roots

list / elements=dictionary

Root directories to propose. A proposed root gives the spoke access to the hub root once the hub authorizes it.

The module proposes the roots that the spoke portal lacks. Roots not listed are left as they are.

A spoke root that already maps to another hub root fails, since a root cannot be changed in place.

Default: []

hub_root

string / required

Absolute path of an existing directory on the hub cluster.

spoke_root

string / required

Absolute path of the spoke root on this cluster. The server creates it, so it must not exist yet, and its parent directory must.

state

string

Whether the spoke portal exists.

Choices:

  • "present" ← (default)

  • "absent"

type

string

The type a new spoke portal is created with.

Used only when the spoke portal is created. The hub decides the type of an accepted portal, so change it with qumulo.cluster.portal_hub; a different value here adds a note and changes nothing.

Choices:

  • "read_write" ← (default)

  • "read_only"

validate_certs

boolean

Verify the cluster’s TLS certificate.

If not set, the value of the QUMULO_VALIDATE_CERTS environment variable is used.

Choices:

  • false

  • true ← (default)

wait

boolean

With state=absent, wait until the spoke portal is gone.

Choices:

  • false

  • true ← (default)

wait_timeout

integer

Seconds to wait for a delete that a portal transition blocks, and for the spoke portal to be gone.

Default: 600

Attributes

Attribute

Support

Description

action_group

Action group: qumulo.cluster.qumulo

Use group/qumulo.cluster.qumulo in module_defaults to set the connection options for this module.

check_mode

Support: full

Can run in check mode and return a changed status prediction without modifying the cluster.

diff_mode

Support: full

Will return details on what has changed, or would change in check mode, when in diff mode.

idempotent

Support: partial

Creating the spoke portal and proposing a root cannot be retried safely (G-PORTAL-ONESHOT). The module lists and matches first and checks the spoke root before either.

Spoke portals carry no ETag, so a concurrent change between the read and a write goes undetected (G-PORTAL-ETAG).

When run twice in a row outside check mode with the same arguments, the second run reports no change.

This assumes that nothing else changed the cluster in between.

Notes

Note

  • API: GET and POST /v2/portal/spokes/, PATCH and DELETE /v2/portal/spokes/{id}, POST /v2/portal/spokes/{id}/roots/, GET /v1/files/{ref}/info/attributes.

  • Idempotency gaps G-PORTAL-ONESHOT and G-PORTAL-ETAG apply.

  • A PATCH that repeats the stored value still rewrites the record and re-runs its connectivity checks (QUIRK-005), so the module sends hub_hosts only when they differ.

  • A delete that a portal transition blocks, such as a drain in progress, is retried until wait_timeout.

Examples

# These tasks carry no connection options, except where a task names another cluster. Set them once for the play
# with module_defaults for group/qumulo.cluster.qumulo, or in the QUMULO_* environment variables.
- name: Propose a read-write portal to the hub, with one root
  qumulo.cluster.portal_spoke:
    hub_cluster_uuid: "{{ hostvars['hub01'].qumulo_cluster_uuid }}"
    hub_hosts:
      - address: 10.0.0.10
      - address: 10.0.0.11
    roots:
      - spoke_root: /hub-data
        hub_root: /data

- name: Propose a second root, leaving the first as it is
  # The spoke root must not exist yet, and its parent must.
  qumulo.cluster.portal_spoke:
    hub_cluster_uuid: "{{ hostvars['hub01'].qumulo_cluster_uuid }}"
    roots:
      - spoke_root: /hub-archive
        hub_root: /archive

- name: Reach the hub at its replacement nodes
  qumulo.cluster.portal_spoke:
    hub_cluster_uuid: "{{ hostvars['hub01'].qumulo_cluster_uuid }}"
    hub_hosts:
      - address: 10.0.0.12
      - address: 10.0.0.13

- name: Preview the portal from the inventory
  qumulo.cluster.portal_spoke:
    hub_cluster_uuid: "{{ hostvars['hub01'].qumulo_cluster_uuid }}"
    hub_hosts: "{{ hostvars['hub01'].qumulo_portal_hosts }}"
    type: read_only
    roots: "{{ qumulo_portal.roots }}"
  check_mode: true
  diff: true
  register: spoke_preview

- name: Show what the module noted, such as a type only the hub can change
  ansible.builtin.debug:
    var: spoke_preview.notes
  when: spoke_preview.notes is defined

- name: Drain the portal on the hub, which decides its type
  # Set the portal to read_only on the hub before deleting the spoke portal.
  qumulo.cluster.portal_hub:
    api_host: hub01.example.com
    api_password: "{{ vault_hub01_admin_password }}"
    expected_cluster_uuid: "{{ hostvars['hub01'].qumulo_cluster_uuid }}"
    spoke_cluster_uuid: "{{ qumulo_cluster_uuid }}"
    type: read_only

- name: Delete the spoke portal after the hub drained it
  qumulo.cluster.portal_spoke:
    hub_cluster_uuid: "{{ hostvars['hub01'].qumulo_cluster_uuid }}"
    state: absent

- name: Delete the spoke portal and return without waiting for it to be gone
  qumulo.cluster.portal_spoke:
    hub_cluster_uuid: "{{ hostvars['hub01'].qumulo_cluster_uuid }}"
    state: absent
    wait: false

- name: Force the delete of the portal to a hub that no longer answers
  # Writes the hub has not received are lost.
  qumulo.cluster.portal_spoke:
    hub_cluster_uuid: "{{ old_hub_cluster_uuid }}"
    state: absent
    allow_data_loss: true

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

expected

dictionary

The values the task wrote, for the options that did not converge.

Returned: when the read-back after a write differs from what was written; after a lost connection the task returns maybe_applied instead

Sample: {"hub_hosts": [{"address": "10.0.0.12", "port": 3713}, {"address": "10.0.0.13", "port": 3713}]}

maybe_applied

boolean

true when a write was sent and the connection was lost before the cluster answered, and reading the portal back did not confirm it. The task fails with changed true.

Returned: on a failure after such a write

Sample: true

notes

list / elements=string

What the module noticed but did not change, such as a type that differs from the accepted portal’s.

Returned: when there is something to note

Sample: ["the hub decides the type of this portal", "read_write; change it to read_only with qumulo.cluster.portal_hub"]

observed

dictionary

What the cluster read back for the keys of expected.

Returned: when the read-back after a write differs from what was written; after a lost connection the task returns maybe_applied instead

Sample: {"hub_hosts": [{"address": "10.0.0.10", "port": 3713}]}

portal

dictionary

The spoke portal after the task, empty after a delete. qumulo.cluster.portal_info reports hubs and spokes in this shape.

In check mode, the portal the task would create holds only the options.

Returned: always

Sample: {"hub_cluster_uuid": "4b3c802f-8201-42b7-bb41-28f562cd8dfd", "hub_hosts": [{"address": "10.0.0.10", "port": 3713}], "roots": [{"authorized": true, "hub_root": "/data", "spoke_root": "/hub-data"}], "spoke_cluster_uuid": "625d63a2-9663-4b0e-9d45-ec119a5a9a49", "spoke_hosts": null, "state": "ACCEPTED", "status": "ACTIVE", "type": "read_write"}

hub_cluster_uuid

string

UUID of the hub cluster.

Returned: success

hub_hosts

list / elements=dictionary

Where this cluster reaches the hub, each with address and port.

Returned: success

roots

list / elements=dictionary

Each root with spoke_root, hub_root and authorized. hub_root is null until the hub reports its path.

Returned: success

spoke_cluster_uuid

string

UUID of this cluster.

Returned: success

spoke_hosts

list / elements=dictionary

Always null on a spoke, which does not record where the hub reaches it.

Returned: success

state

string

PENDING until the hub accepts the portal, then ACCEPTED, or a state of a transition such as QUIESCING.

Returned: success

status

string

ACTIVE, INACTIVE, DEGRADED or DISCONNECTED.

Returned: success

type

string

read_write or read_only.

Returned: success
