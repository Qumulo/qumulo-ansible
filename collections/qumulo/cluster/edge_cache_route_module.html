qumulo.cluster.edge_cache_route module – Choose how to bring a Qumulo edge’s cache to a target size

Note

This module is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.edge_cache_route.

New in qumulo.cluster 0.1.0

  • Synopsis

  • Parameters

  • Attributes

  • Notes

  • Examples

  • Return Values

Synopsis

  • Compares a target capacity clamp with an edge’s file system size, its stored clamp and its license ceiling, and returns the route the qumulo.cluster.edge_cache_resize role takes. The inputs are options, read with qumulo.cluster.cluster_info.

  • A pure computation from its options. It sends no request, takes no connection options, and is not in the qumulo.cluster.qumulo action group, so module_defaults for that group do not reach it.

  • The file system’s size stands in for the provisioned capacity, which no API reports, so the comparison is approximate (G-CLAMP-TOL).

  • within when the file system is within margin of the target.

  • below_floor when the file system is more than margin above the target and the target is below floor (G-EDGE-FLOOR). The reason suggests a free_threshold for qumulo.cluster.portal_eviction_settings.

  • rebuild when the file system is more than margin above the target otherwise (G-CLAMP-SHRINK, G-UUID, G-LICENSE).

  • blocked_license when the file system is more than margin below the target and the license ceiling is below the target (G-LICENSE). The ceiling is license_cap; on an unprotected edge without one, it is 1 TB (G-EDGE-FLOOR).

  • platform_limited when the file system is more than margin below the target but stored already allows it. Either the platform’s disks cannot provision more, or a raised license cap has not applied yet; the module cannot tell which (G-LICENSE).

  • grow otherwise; raising the clamp then re-forms quorum once (G-CLAMP-BOUNCE).

Parameters

Parameter

Comments

floor

integer

The capacity a rebuilt edge provisions at formation, if its platform is larger (G-EDGE-FLOOR). A target below it routes to below_floor rather than rebuild.

It does not move the 1 TB ceiling of an unlicensed edge.

Default: 1000000000000

license_cap

integer

The license’s usable capacity cap in bytes, or null when there is none.

margin

any

How close the file system must be to the target to count as that size, in bytes or as a size with a unit.

Defaults to 10% of the target.

stored

integer

The stored capacity clamp in bytes, or null when none is set; an unset clamp limits nothing.

target

any / required

The target clamp, in bytes or as a size with a unit such as 4TB (10^12 bytes) or 4TiB (2^40 bytes).

total

integer / required

The file system’s total_size_bytes.

unprotected_edge

boolean / required

Whether the cluster is an unprotected edge, as qumulo.cluster.cluster_info reports it in product.unprotected_edge.

Required. An unprotected edge without a license cap is held to 1 TB.

Choices:

  • false

  • true

Notes

Note

  • API: none.

  • Registers: G-CLAMP-BOUNCE, G-CLAMP-TOL, G-CLAMP-SHRINK, G-EDGE-FLOOR, G-LICENSE, G-UUID.

Examples

# The module runs on the controller and takes no connection options. Only the cluster_info read and the clamp write
# connect: set their options once for the play with module_defaults for group/qumulo.cluster.qumulo, or in the
# QUMULO_* environment variables.
- name: Read the edge's clamp, license, size and product type
  qumulo.cluster.cluster_info:
    gather_subset: [capacity, license, filesystem, product]
  register: info

- name: Choose the route to a 4 TB cache
  qumulo.cluster.edge_cache_route:
    target: 4TB
    stored: "{{ info.cluster.capacity_clamp }}"
    license_cap: "{{ info.cluster.license.usable_capacity_cap }}"
    total: "{{ info.cluster.filesystem.total_size_bytes }}"
    unprotected_edge: "{{ info.cluster.product.unprotected_edge }}"
  register: plan

- name: Grow the cache only when the route is a plain clamp write
  # Uses the route registered by the task above. Any other route needs a decision: a rebuild, a license, or a free threshold.
  qumulo.cluster.capacity_clamp:
    capacity_clamp: 4TB
  when: plan.route == 'grow'

- name: Ask whether a 500 GB cache on a 2 TB licensed edge needs a rebuild
  # The inputs are plain numbers, so this answers a what-if without reading a cluster.
  qumulo.cluster.edge_cache_route:
    target: 500GB
    stored: 2000000000000
    total: 2000000000000
    license_cap: 2000000000000
    unprotected_edge: true
  register: what_if

- name: Treat a file system within 80 GB of the target as that size
  qumulo.cluster.edge_cache_route:
    target: 4TB
    stored: 4000000000000
    total: 3950000000000
    unprotected_edge: false
    margin: 80GB
  register: tight_plan

Key

Description

ceiling

integer

The most the license allows in bytes, or null when nothing caps it.

Returned: success

Sample: 4000000000000

floor

integer

The floor in bytes.

Returned: success

Sample: 1000000000000

license_cap

integer

license_cap, or null.

Returned: success

Sample: 4000000000000

margin

integer

The margin in bytes.

Returned: success

Sample: 400000000000

reason

string

Why this route, in one sentence.

Returned: success

Sample: "the target is more than 400000000000 bytes above the file system (1000000000000 bytes), and the clamp (1000000000000 bytes) is below it"

rounding_tolerance

integer

How far the stored clamp may sit from the target once written, in bytes, the larger of 1% of the target and 8 GiB, as qumulo.cluster.capacity_clamp takes it by default (QUIRK-012).

Returned: success

Sample: 40000000000

route

string

within, grow, platform_limited, blocked_license, below_floor or rebuild.

Returned: success

Sample: "grow"

stored

integer

The stored clamp in bytes, or null.

Returned: success

Sample: 1000000000000

target

integer

The target in bytes.

Returned: success

Sample: 4000000000000

total

integer

The file system’s size in bytes.

Returned: success

Sample: 1000000000000
