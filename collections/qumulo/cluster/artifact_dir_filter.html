qumulo.cluster.artifact_dir filter – Where the collection’s roles keep a host’s records and secrets

Note

This filter plugin is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.artifact_dir.

New in qumulo.cluster 0.1.0

  • Synopsis

  • Input

  • Positional parameters

  • Examples

  • Return Value

Synopsis

  • The artifacts directory beside the outermost inventory source on disk that holds the file defining the host. It is never inside the source.

  • An empty string when no inventory source on disk holds the host, as for a host list given with -i edge01,.

  • The default of cluster_baseline_artifact_dir, cluster_upgrade_artifact_dir and edge_rebuild_artifact_dir, and through the last, of replication_pair_artifact_dir.

Input

This describes the input of the filter, the value before | qumulo.cluster.artifact_dir.

Parameter

Comments

Input

list / elements=path / required

The inventory sources, as ansible_inventory_sources gives them.

Positional parameters

This describes positional parameters of the filter. These are the values positional1, positional2 and so on in the following example: input | qumulo.cluster.artifact_dir(positional1, positional2, ...)

Parameter

Comments

inventory_file

path / required

The file that defines the host, as inventory_file gives it.

Examples

- name: Show where this host's records and secrets go
  ansible.builtin.debug:
    msg: "{{ ansible_inventory_sources | qumulo.cluster.artifact_dir(inventory_file | default('')) }}"

- name: Stop before a role needs an artifact directory the host does not have
  # A host from a host list given with -i, as in -i edge01, comes from no inventory file, so it has none.
  ansible.builtin.assert:
    that:
      - ansible_inventory_sources | qumulo.cluster.artifact_dir(inventory_file | default('')) != ''
    fail_msg: "{{ inventory_hostname }} comes from no inventory file; set the role's *_artifact_dir variable."

- name: Keep a host's artifacts in the directory the roles would choose, for a task of your own
  ansible.builtin.file:
    path: "{{ ansible_inventory_sources | qumulo.cluster.artifact_dir(inventory_file | default('')) }}/{{ inventory_hostname }}"
    state: directory
    mode: "0700"
  delegate_to: localhost
  when: ansible_inventory_sources | qumulo.cluster.artifact_dir(inventory_file | default('')) | length > 0

Return Value

Key

Description

Return value

path

The directory’s path, or an empty string when no inventory source on disk holds the host.

Returned: always

Sample: "/srv/qumulo/inventory/artifacts"
