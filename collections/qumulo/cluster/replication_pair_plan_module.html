qumulo.cluster.replication_pair_plan module – Join the source’s and the target’s check passes of a replication relationship into one decision

Note

This module is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.replication_pair_plan.

New in qumulo.cluster 0.1.0

Synopsis

  • Joins the check-mode result of qumulo.cluster.replication_relationship on the source and that of qumulo.cluster.replication_target on the target into one decision. The qumulo.cluster.replication_pair role runs both checks before it writes on either cluster, passes both results here, and acts on status.

  • A pure computation. It sends no request, takes no connection options, and is not in the qumulo.cluster.qumulo action group, so module_defaults for that group do not reach it.

  • status is go when nothing stops the relationship, held or refused otherwise. Every unmet condition of both checks is reported at once in unmet, the source’s and the target’s in one reporting order.

  • held when, while previous_source_cluster_uuids is set, row O2 is unmet and not lifted with a holder from one of those UUIDs, or row O4 is unmet and not lifted. message then names the copy back into the source directory and the release that lets the relationship go ahead.

  • With source_license_rule, a held relationship whose holder allows a restore has message name the restore instead of the copy, with the release only as the way to keep the replica as plain data, and restore_form is true. The holder allows it when it is from a previous UUID of the source, ESTABLISHED, read-only and with a recovery point, row O2 is not lifted, the source directory holds no file, and source_replication_address is an IP literal. The full check is the restore’s own step 1.

  • refused for any other unmet condition that nothing lifts, a check that failed for another reason, a release entry that lifts nothing in this run, and allow_non_empty_target for a target directory the target host does not declare.

  • A source row O3 (an ENDED record of the key with no live one) appears on the target’s check as row O5. That O5 entry is left out of unmet, and target_release gives the target’s passes each release entry that names O3 with O5 added.

  • releases holds one entry for each record id that binds a row no release lifts, with every row both checks reported on that record.

  • With removed, the result of qumulo.cluster.replication_target with state=absent, which has no check pass, only the release entries that deleted no record count, and each refuses.

Parameters

Parameter

Comments

allow_non_empty_target

boolean

The relationship entry’s consent to replace a target directory that holds entries (row O1).

Choices:

  • false ← (default)

  • true

previous_source_cluster_uuids

list / elements=string

UUIDs the source cluster had before a rebuild; while any is set, a relationship can be held.

Default: []

release

list / elements=string

The qumulo_replication_release entries that name this relationship, each <target host>:<target path>@<record id>:<rows>. An entry for another host or path fails.

Default: []

removed

dictionary

For a removal, the result of qumulo.cluster.replication_target with state=absent. source and target are then ignored.

source

dictionary

The result of qumulo.cluster.replication_relationship in check mode, a refusal included, registered with failed_when false or ignore_errors; a result with msg counts as a failed check.

Omit it, and target, to have only target_release, target_declared and ancestors returned.

source_cluster_uuid

string

The source’s current cluster UUID, which the restore form names.

source_host

string

The source’s inventory host, which the restore form names.

source_license_rule

string

The license rule’s answer for the source host, which chooses the restore form’s sentence. expected for a qumulo_edges host that does not declare qumulo_capacity.license none, whose second pass restores once the license applies; none for one that does; outside_edges for any other host, which playbooks/replication_restore.yml restores.

Omit it for the message without a restore form, which names the copy and the release. With it, source_host, source_path and source_cluster_uuid are required.

Choices:

  • "expected"

  • "none"

  • "outside_edges"

source_path

string

The source directory, which the restore form names.

source_replication_address

string

The source host’s qumulo_replication_address; the restore form needs an IP literal.

target

dictionary

The result of qumulo.cluster.replication_target in check mode, a refusal included.

target_directories

list / elements=dictionary

The target host’s qumulo_directories, each with path and an optional state. The consent counts only for a target directory declared there, and the declared ancestors of the target directory are created before it.

Default: []

target_host

string / required

The target’s inventory host, as the release entries name it.

target_path

string / required

The target directory.

Attributes

Attribute

Support

Description

check_mode

Support: full

This action does not modify the cluster.

Can run in check mode and return a changed status prediction without modifying the cluster.

diff_mode

Support: none

This action does not modify the cluster.

Will return details on what has changed, or would change in check mode, when in diff mode.

idempotent

Support: full

This action does not modify the cluster.

When run twice in a row outside check mode with the same arguments, the second run reports no change.

This assumes that nothing else changed the cluster in between.

Notes

Note

  • API: none.

  • Registers: G-REPL-PEER, a rebuilt source’s old record holds its replica until a release; G-REPL-OVERWRITE, the overwrite table the two checks evaluate.

Examples

- name: Check the source side of the relationship without writing
  qumulo.cluster.replication_relationship:
    source_path: /projects
    target_cluster_uuid: "{{ hostvars['dr01'].qumulo_cluster_uuid }}"
    target_path: /replicas/edge01-projects
    target_address: "{{ hostvars['dr01'].qumulo_replication_address }}"
    inventory_cluster_uuids: "{{ groups['qumulo_clusters'] | map('extract', hostvars, 'qumulo_cluster_uuid') | list }}"
    recreate_changed_peer: true
  check_mode: true
  register: source_check
  # A refusal is a result to join, not the end of the play; it keeps its msg and unmet.
  failed_when: false

- name: Check the target side of the relationship without writing
  qumulo.cluster.replication_target:
    source_cluster_uuid: "{{ hostvars['edge01'].qumulo_cluster_uuid }}"
    source_path: /projects
    target_path: /replicas/edge01-projects
    source_creates: "{{ source_check.relationship.id | default(none) is none }}"
    relationship_id: "{{ source_check.relationship.id | default(omit) }}"
    directory_pending: true
    source_empty: "{{ source_check.source_empty | default(omit) }}"
  module_defaults:
    group/qumulo.cluster.qumulo: "{{ dr01_connection }}"
  check_mode: true
  register: target_check
  failed_when: false

- name: Join both checks into one decision
  qumulo.cluster.replication_pair_plan:
    source: "{{ source_check }}"
    target: "{{ target_check }}"
    release: "{{ qumulo_replication_release | default([]) | select('match', 'dr01:/replicas/edge01-projects/?@') | list }}"
    target_host: dr01
    target_path: /replicas/edge01-projects
    previous_source_cluster_uuids: "{{ hostvars['edge01'].qumulo_previous_cluster_uuids | default([]) }}"
    target_directories: "{{ hostvars['dr01'].qumulo_directories | default([]) }}"
  register: plan

- name: Stop before any write unless both sides may go ahead
  ansible.builtin.assert:
    that: plan.status == 'go'
    fail_msg: "{{ plan.message }}"
    quiet: true

- name: Print the restore, not the copy, when a rebuilt edge's old record holds its replica
  # source_check and target_check are the registers of the two checks above. The edge is in qumulo_edges, so its
  # license rule is "expected".
  qumulo.cluster.replication_pair_plan:
    source: "{{ source_check }}"
    target: "{{ target_check }}"
    release: "{{ qumulo_replication_release | default([]) | select('match', 'dr01:/replicas/edge01-projects/?@') | list }}"
    target_host: dr01
    target_path: /replicas/edge01-projects
    previous_source_cluster_uuids: "{{ hostvars['edge01'].qumulo_previous_cluster_uuids }}"
    target_directories: "{{ hostvars['dr01'].qumulo_directories | default([]) }}"
    source_host: edge01
    source_path: /projects
    source_cluster_uuid: "{{ hostvars['edge01'].qumulo_cluster_uuid }}"
    source_license_rule: expected
    source_replication_address: "{{ hostvars['edge01'].qumulo_replication_address }}"
  register: restore_plan

- name: Check the target side with the consent to replace a target directory that holds entries
  # The consent goes to both sides: allow_non_empty_directory lifts the target check's row O1, and the plan's
  # allow_non_empty_target adds a refusal when the target host does not declare the directory.
  qumulo.cluster.replication_target:
    source_cluster_uuid: "{{ hostvars['edge01'].qumulo_cluster_uuid }}"
    source_path: /projects
    target_path: /replicas/edge01-projects
    source_creates: "{{ source_check.relationship.id | default(none) is none }}"
    relationship_id: "{{ source_check.relationship.id | default(omit) }}"
    directory_pending: true
    source_empty: "{{ source_check.source_empty | default(omit) }}"
    allow_non_empty_directory: true
  module_defaults:
    group/qumulo.cluster.qumulo: "{{ dr01_connection }}"
  check_mode: true
  register: consent_target_check
  failed_when: false

- name: Allow the replica to replace a target directory that holds entries, only if dr01 declares it
  # allow_non_empty_target counts only for a target directory in the target host's qumulo_directories.
  qumulo.cluster.replication_pair_plan:
    source: "{{ source_check }}"
    target: "{{ consent_target_check }}"
    target_host: dr01
    target_path: /replicas/edge01-projects
    allow_non_empty_target: true
    target_directories: "{{ hostvars['dr01'].qumulo_directories | default([]) }}"
  register: consent_plan

- name: Find the target directory's declared ancestors and the target's release entries, with no checks to join
  qumulo.cluster.replication_pair_plan:
    release: "{{ qumulo_replication_release | default([]) | select('match', 'dr01:/replicas/edge01-projects/?@') | list }}"
    target_host: dr01
    target_path: /replicas/edge01-projects
    target_directories: "{{ hostvars['dr01'].qumulo_directories | default([]) }}"
  register: target_view

- name: Refuse a removal whose release entries deleted nothing
  # target_removed is the result of the target's removal, which has no check pass.
  qumulo.cluster.replication_pair_plan:
    removed: "{{ target_removed }}"
    release: "{{ qumulo_replication_release | default([]) | select('match', 'dr01:/replicas/edge01-projects/?@') | list }}"
    target_host: dr01
    target_path: /replicas/edge01-projects
  register: removal_plan
  failed_when: removal_plan.status != 'go'

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

ancestors

list / elements=dictionary

The entries of target_directories above the target directory, outermost first, each with its path without a trailing slash.

Returned: always

blocking

list / elements=dictionary

The entries of unmet that stop the relationship, neither lifted nor pending.

Returned: when source is given and removed is not

failures

list / elements=string

The failures of a check that no unmet entry explains, such as a cluster that did not answer.

Returned: when source is given and removed is not

holders

list / elements=dictionary

The target’s holders, as qumulo.cluster.replication_target returns them in its holders.

Returned: when source is given and removed is not

lifting_nothing

list / elements=string

The release entries that lift nothing in this run; each refuses the relationship.

Returned: when source or removed is given

message

string

Why the relationship is held or refused, with what would lift it; empty for go.

Returned: when source or removed is given

pairing

boolean

Whether the source creates the relationship or the target authorizes it, so that the capacity gate applies. The target authorizes when its check evaluated the overwrite table, which it does only before an authorize, and so returned replaces.

Returned: when source is given and removed is not

releases

list / elements=string

The release entries to print, <target host>:<target path>@<record id>:<rows>, one per record id that binds a row no release lifts, with every row both checks reported on that record.

Returned: when source is given and removed is not

Sample: ["dr01:/replicas/edge01-projects@9465828e-7dcf-466e-a550-78ed0bd6b79b:O2,O4"]

restore_form

boolean

Whether message names the restore in place of the copy, printing the release only as the way to keep the replica as plain data instead. The rebuild report places such a message without the baseline run that would release it.

Returned: when source is given and removed is not

status

string

go, held or refused.

Returned: when source or removed is given

Sample: "held"

target_declared

boolean

Whether target_directories declares the target directory.

Returned: always

target_release

list / elements=string

release as the target’s passes take it, each entry that names O3 with O5 added.

Returned: always

unmet

list / elements=dictionary

Every unmet condition of both checks, in the shape the two modules return it, with side, source or target. Other conditions come first, then the overwrite table’s rows in the reporting order.

Returned: when source is given and removed is not
