qumulo.cluster.url_secret filter – The secret parts of an upgrade image’s URL

Note

This filter plugin is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.url_secret.

New in qumulo.cluster 0.1.0

  • Synopsis

  • Input

  • Examples

  • Return Value

Synopsis

  • The query string and the user information of one qumulo_upgrade_images entry’s image, each on its own, so that each can be masked on its own. Both are null for a path, or for a URL with neither.

  • The value is what qumulo.cluster.upgrade takes as image_secret, which the module joins back to image, the URL given through qumulo.cluster.redact_images. The cluster_upgrade role passes it that way.

Input

This describes the input of the filter, the value before | qumulo.cluster.url_secret.

Parameter

Comments

Input

any / required

One entry of qumulo_upgrade_images, a URL, a path, or a mapping {version, image, kind, build}.

Examples

- name: Upgrade to an entry given as a URL, with its secret parts passed apart from it
  vars:
    entry: "{{ qumulo_upgrade_images[0] }}"
  qumulo.cluster.upgrade:
    image: "{{ [entry] | qumulo.cluster.redact_images | first }}"
    image_secret: "{{ entry | qumulo.cluster.url_secret }}"

- name: Upgrade to an entry given as a mapping, whose image is its image field
  vars:
    entry: "{{ qumulo_upgrade_images[0] }}"
  qumulo.cluster.upgrade:
    image: "{{ ([entry] | qumulo.cluster.redact_images | first).image }}"
    image_secret: "{{ entry | qumulo.cluster.url_secret }}"
    version: "{{ entry.version }}"
    build: "{{ entry.build | default(omit) }}"

Return Value

Key

Description

Return value

dictionary

The secret parts of the image’s URL.

Returned: always

query

string

The query string of the URL, or null when there is none.

Returned: success

Sample: "X-Amz-Signature=abc&X-Amz-Expires=14400"

userinfo

string

The user information of the URL, such as user:password, or null when there is none.

Returned: success

Sample: "user:p%40ss"
