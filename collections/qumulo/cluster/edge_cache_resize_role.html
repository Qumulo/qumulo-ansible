qumulo.cluster.edge_cache_resize role – Bring a Qumulo edge’s cache to a target size, by the least disruptive route

Note

This role is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.edge_cache_resize.

Entry point main – Bring a Qumulo edge’s cache to a target size, by the least disruptive route

New in qumulo.cluster 0.1.0

Synopsis

  • Reads the edge’s file system size (C), stored capacity clamp (R), license ceiling (L) and product type, and chooses a route to the target clamp T with qumulo.cluster.edge_cache_route. L is the license’s usable capacity cap; on an unprotected edge without one it is 1 TB, the most an unlicensed edge provisions. The role fails when the product type is unknown.

  • within when C is within the margin of T.

  • grow when C is more than the margin below T, R is below T and L allows T. Raises the clamp to T, which re-forms quorum once, then reads C again. If C is still more than the margin below T, the route becomes platform_limited.

  • platform_limited when C is more than the margin below T but R already allows T. Writes nothing; the reason names the platform’s disks, or a license cap that applies only at the next quorum formation.

  • blocked_license when L is below T. Fails naming the license the edge’s UUID needs from Nexus (G-LICENSE).

  • below_floor when C is more than the margin above T and T is below the floor, which a rebuilt edge provisions again (G-EDGE-FLOOR). Needs qumulo_capacity.free_threshold, and suggests a value.

  • rebuild when C is more than the margin above T otherwise, since provisioned capacity never shrinks (G-CLAMP-SHRINK). Fails with the plan to rebuild the edge, which then has a new UUID and needs a new license from Nexus (G-UUID, G-LICENSE).

  • On every route that does not fail, applies qumulo_capacity.free_threshold when it is declared.

  • With edge_cache_resize_plan_only, and so under --check, it only reports the route and its inputs.

  • Sets the facts edge_cache_resize_route, the route taken, and edge_cache_resize_plan, the result of qumulo.cluster.edge_cache_route, which holds the route, the reason, and T, R, L, C, the margin and the floor in bytes.

  • Connects through the play’s module_defaults for group/qumulo.cluster.qumulo, as playbooks/edge_cache_resize.yml sets them. It runs no qumulo.cluster.cluster_guard itself; playbooks/edge_cache_resize.yml runs one first.

Parameters

Parameter

Comments

edge_cache_resize_allow_rebuild

boolean

On the rebuild route, rebuild the edge with the edge_rebuild role, phase all, instead of failing with the plan. Needs edge_rebuild_reinstall_tasks, and the replay’s own variables, -e qumulo_rebuild=true among them.

Choices:

  • false ← (default)

  • true

edge_cache_resize_floor_bytes

integer

The capacity a rebuilt edge provisions at formation, if its platform is larger (G-EDGE-FLOOR). A target below it routes to below_floor rather than rebuild.

It does not move the 1 TB ceiling of an unlicensed edge.

The qumulo.cluster.edge_rebuild role also reads it, to refuse a declared clamp more than its rounding tolerance below min(1 TB, this); see that role’s description.

Default: 1000000000000

edge_cache_resize_margin_bytes

any

How close C must be to T to count as that size, in bytes or as a size with a unit.

Unset means 10% of T.

edge_cache_resize_plan_only

boolean

Report the route and its inputs, and change nothing. True by default under --check.

Choices:

  • false

  • true

edge_cache_resize_rounding_tolerance

any

How far above T a stored clamp may be and still count as T rounded up to a provisioning unit, passed to qumulo.cluster.capacity_clamp as rounding_tolerance.

Unset means the module’s own default, the larger of 1% of T and 8 GiB. The role calls the module only on the grow route, where the stored clamp is below T, so the tolerance decides only whether the clamp read back after the write draws a warning.

edge_rebuild_reinstall_tasks

path

The tasks file that reinstalls the edge between the predestroy and replay phases of edge_rebuild.

qumulo_capacity

dictionary / required

The edge’s capacity settings, as the inventory declares them.

clamp

any / required

The target clamp T, in bytes or as a size with a unit, such as 4TB (10^12 bytes) or 4TiB (2^40 bytes).

free_threshold

float

The fraction of capacity, from 0.0 to 1.0, that the edge keeps free by evicting cached spoke data.

Declared state, applied on every route that does not fail; needed on below_floor.

license

string

What the inventory expects of the license, pending or required, or none for an edge that runs without a license, within the capacity its formation gave it (G-EDGE-FLOOR). The license step of a baseline writes a none edge’s clamp with no license. It then limits a license that arrives later, and a clamp above 1 TB provisions nothing more until a license arrives.

Read by the license step of a baseline, not by this role.

Choices:

  • "pending"

  • "required"

  • "none"

license_document

any

The license document issued for the edge’s UUID, encrypted with ansible-vault.

Applied by the license step of a baseline and by playbooks/edge_license_complete.yml, not by this role.
