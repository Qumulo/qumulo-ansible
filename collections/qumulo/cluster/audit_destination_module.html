qumulo.cluster.audit_destination module – Manage a Qumulo cluster’s audit log destination

Note

This module is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.audit_destination.

New in qumulo.cluster 0.1.0

  • Synopsis

  • Parameters

  • Attributes

  • Notes

Synopsis

  • Creates, changes or deletes one audit log destination, found by its name. A destination is a syslog server, a CloudWatch log group, or the cluster’s local audit log.

  • A change sends the destination’s whole configuration in one write, with the cluster’s values for the options left unset. A change of type drops the options of the old type.

  • When terraform_owned_areas lists audit.cloudwatch, the module refuses a task that would create, change or delete a CloudWatch destination, or change a destination to or from that type. When it lists audit, the module refuses any task that would write a destination. take_over_from_terraform=true lifts both.

  • These refusals come before any write, in check mode too. A task that would change nothing, and state=absent for a destination that does not exist, are not refused.

  • An option of another type than the destination’s fails before any write. So does a name that more than one destination has, naming their ids, and an existing destination of a type the module does not know, unless type replaces it with a type the module knows.

Parameters

Parameter

Comments

api_host

string / required

Address or name of the Qumulo cluster’s REST API.

An IPv6 address is given bare, as fd00::5; the URL puts it in brackets.

If not set, the value of the QUMULO_API_HOST environment variable is used.

api_password

string

Password of api_username.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_PASSWORD environment variable is used.

api_port

integer

TCP port of the REST API.

If not set, the value of the QUMULO_API_PORT environment variable is used.

Default: 8000

api_token

string

An access token, sent in place of logging in.

An access token is bound to one cluster and does not survive a rebuild.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_TOKEN environment variable is used.

api_username

string

User that logs in with api_password.

If not set, the value of the QUMULO_API_USERNAME environment variable is used.

Default: "admin"

ca_path

path

PEM file of the certificate authority that signed the cluster’s certificate.

On Python 3.13 and later this must be a CA certificate, with basic constraints.

A bare self-signed leaf certificate cannot be pinned here on Python 3.13 and later; such a cluster is reached only with validate_certs=false.

If not set, the value of the QUMULO_CA_PATH environment variable is used.

enabled

boolean

Whether the cluster sends audit logs to the destination. A new destination is enabled unless this is false.

Choices:

  • false

  • true

expected_cluster_uuid

string

The UUID the cluster at api_host must have.

Before the first credentials are sent, the module reads the cluster’s UUID from GET /v1/node/state, which needs no login, and fails when it differs, so that no credentials are sent to the wrong cluster. On a mismatch the task fails with live_cluster_uuid and expected_cluster_uuid in its result.

An empty value disables this identity guard, and a module that logs in warns.

If not set, the value of the QUMULO_EXPECTED_CLUSTER_UUID environment variable is used.

log_format

string

The format of each syslog message. For SYSLOG only; a new destination uses csv.

Choices:

  • "csv"

  • "json"

log_group_name

string

The CloudWatch log group. For CLOUDWATCH only.

name

string / required

The destination’s name, which the module finds it by.

syslog, cloudwatch and local are reserved for a destination of the matching type, and a LOCAL destination must be named local. A name outside these rules fails before any write.

region

string

The AWS region of the log group. For CLOUDWATCH only.

request_timeout

integer

Seconds to wait for one HTTP response.

If not set, the value of the QUMULO_REQUEST_TIMEOUT environment variable is used.

Default: 60

retry_timeout

integer

Seconds to keep retrying a request that is safe to resend, after a lost connection or an HTTP 502, 503 or 504.

If not set, the value of the QUMULO_RETRY_TIMEOUT environment variable is used.

Default: 300

server_address

string

The syslog server’s host name or IP address. For SYSLOG only.

server_port

integer

The syslog server’s port. For SYSLOG only.

The cluster refuses to enable a syslog destination without one.

state

string

Whether the destination exists.

Choices:

  • "present" ← (default)

  • "absent"

take_over_from_terraform

boolean

Manage the destination although terraform_owned_areas lists audit or audit.cloudwatch.

Choices:

  • false ← (default)

  • true

terraform_owned_areas

list / elements=string

The areas Terraform owns, as the inventory’s qumulo_terraform_owned_areas lists them. Only audit and audit.cloudwatch concern this module.

Default: []

type

string

Where the destination sends audit logs. Needed to create a destination; unset keeps the destination’s.

CLOUDWATCH works only on a cluster in AWS; elsewhere the cluster refuses it, and the module fails with its reason.

Choices:

  • "SYSLOG"

  • "CLOUDWATCH"

  • "LOCAL"

validate_certs

boolean

Verify the cluster’s TLS certificate.

If not set, the value of the QUMULO_VALIDATE_CERTS environment variable is used.

Choices:

  • false

  • true ← (default)

Use group/qumulo.cluster.qumulo in module_defaults to set the connection options for this module.

check_mode

Can run in check mode and return a changed status prediction without modifying the cluster.

Support: full

Will return details on what has changed, or would change in check mode, when in diff mode.

idempotent

Support: full

When run twice in a row outside check mode with the same arguments, the second run reports no change.

This assumes that nothing else changed the cluster in between.

Notes

Note

  • API: GET /v2/audit/destinations/ to find the destination by name; POST /v2/audit/destinations/ to create it; GET, PUT and DELETE /v2/audit/destinations/{id}, with If-Match.

  • A change to an existing destination is written as its whole configuration with PUT, never PATCH (QUIRK-062).

  • Changing type in place is not tested on a running cluster (G-MON-AUDIT-RETYPE).

  • The module does not wait for a destination to connect; each node’s connection status is at GET /v2/audit/destinations/{id}/status.

Examples

# These tasks carry no connection options. Set them once for the play with module_defaults for
# group/qumulo.cluster.qumulo, or in the QUMULO_* environment variables.
- name: Send audit logs to the SIEM as JSON
  qumulo.cluster.audit_destination:
    name: siem
    type: SYSLOG
    server_address: siem.example.com
    server_port: 514
    log_format: json

- name: Move the SIEM destination to another port
  qumulo.cluster.audit_destination:
    name: siem
    server_port: 6514

- name: Keep the cluster's local audit log
  qumulo.cluster.audit_destination:
    name: local
    type: LOCAL

# CLOUDWATCH works only on a cluster in AWS.
- name: Send audit logs to a CloudWatch log group
  qumulo.cluster.audit_destination:
    name: audit-cloudwatch
    type: CLOUDWATCH
    log_group_name: /qumulo/audit
    region: us-west-2

- name: Preview pausing the SIEM destination
  qumulo.cluster.audit_destination:
    name: siem
    enabled: false
  check_mode: true
  diff: true
  register: audit_preview

- name: Show the destination the change would leave
  ansible.builtin.debug:
    var: audit_preview.audit_destination

- name: Pause sending audit logs to the SIEM
  qumulo.cluster.audit_destination:
    name: siem
    enabled: false

- name: Stop sending audit logs to the old SIEM
  qumulo.cluster.audit_destination:
    name: old-siem
    state: absent

# With audit.cloudwatch listed but not audit, the module refuses to write a CloudWatch destination, but still writes a
# syslog one.
- name: Send audit logs to the SIEM while Terraform owns the CloudWatch destination
  qumulo.cluster.audit_destination:
    name: siem
    type: SYSLOG
    server_address: siem.example.com
    server_port: 514
    terraform_owned_areas: [audit.cloudwatch]

- name: Manage a CloudWatch destination that Terraform owns
  qumulo.cluster.audit_destination:
    name: audit-cloudwatch
    type: CLOUDWATCH
    log_group_name: /qumulo/audit
    region: us-west-2
    terraform_owned_areas: "{{ qumulo_terraform_owned_areas }}"
    take_over_from_terraform: true
