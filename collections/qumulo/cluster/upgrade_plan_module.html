qumulo.cluster.upgrade_plan module – Plan a fleet’s Qumulo Core upgrade, hop by hop, before anything is sent

Note

This module is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.upgrade_plan.

New in qumulo.cluster 0.1.0

Synopsis

  • Turns every inventory host’s reads and upgrade variables into the run’s plan, which the qumulo.cluster.cluster_upgrade role follows. The plan is a list of hops. A hop takes the hosts it moves to one release; each host takes its own hops to its own target, each the furthest entry of its images list that Qumulo Core’s quarterly rule accepts (G-UPGRADE-PATH). A host whose next hop is to another release does not move in the hop, and the plan notes that.

  • A pure computation. It sends no request, takes no connection options, and is not in the qumulo.cluster.qumulo action group, so module_defaults for that group do not reach it.

  • Within a hop the commits are cut into units, a portal component’s moving members in waves, its spokes before their hub, or one cluster alone. The units are ordered by qumulo_upgrade_after and by replication, a target before its source.

  • Any refusal stops the whole plan. The module then fails with every refusal’s message, and still returns plan. The refusals come from the inventory and the reads alone, such as a limited release without the waiver (G-UPGRADE-LETTER), a reboot set size above the configured tolerance (G-UPGRADE-COUNT), or a commit record a commit that did not finish left (G-UPGRADE-RECORD).

  • Each warning, such as an unlicensed edge’s (G-UPGRADE-LICENSE), is also printed, and none stops the run.

  • Each host’s images reach the module through the filter qumulo.cluster.redact_images, so no field of the result holds a URL’s query string or user information. The module has no no_log option, so host names, releases and numbers read in full.

  • With window, the module answers only whether a hop’s commits may begin now, by the hop’s maintenance windows.

Parameters

Parameter

Comments

aggressive

boolean

The run’s qumulo_upgrade_aggressive.

The plan refuses true in this release. With false, each host reboots as its reboot gives.

Choices:

  • false ← (default)

  • true

forks

integer

The play’s forks, by which each hop’s lease counts its batches.

hosts

list / elements=dictionary

Every inventory host, not only the play’s, each a mapping.

name, the inventory host; reached, whether the play reaches it, and in_play, whether it is still in the play after its reads, both true when unset.

From its reads, when the play read it, cluster_uuid, the cluster_id of qumulo.cluster.cluster_info‘s node subset; version and build, its version and build_id from the version subset; status, the upgrade status with its URLs redacted, protection, the upgrade subset’s {type, configured_node_failures, remaining_node_failures}, license_state, unprotected_edge, live_hub_portals, live_spoke_portals and unavailable_subsets.

From its variables, target, images, already through qumulo.cluster.redact_images, reboot, reboot_set_size, maintenance_windows, window_timezone, after and allow_limited_release, its qumulo_upgrade_* variables; cluster_kind, its qumulo_cluster_kind; portal_hub, its qumulo_portal.hub; and relationships, its qumulo_replication_relationships.

commit_record, {path, text} when the host’s commit record is on disk.

Required unless window is given.

limit

list / elements=string

The hosts of the run’s --limit, or null for the whole inventory.

now

string

The run’s start, as an ISO 8601 date and time, such as 2026-11-04T17:00:00Z. A time with an offset is converted to UTC, and one without an offset is read as UTC. A value that is not ISO 8601 is refused.

It is the clock of the window answer, and the start of the week in which the hop’s maintenance windows must share some time.

Defaults to the controller’s clock.

restore_files

dictionary

The restore records and restore locks on the controller, {records, locks}, each list as qumulo.cluster.replication_restore_info returns it.

Each record, and each live lock on a host the run does not lock itself, is a warning (W1) for each host the plan moves or reboots among the hosts it names. A record names its edge (host), its key’s target_host and every target of the edge’s present relationships. A lock names its host and that host’s present targets. A lock that is gone or expired is not a warning.

Default: {}

locks

list / elements=dictionary

The locks, each read for host, path, holder, pid, controller, lease_expiry and liveness.

Default: []

records

list / elements=dictionary

The records, each read for host, path and key.

Default: []

throttle

integer

The prepares’ throttle, the role’s cluster_upgrade_prepare_throttle, for each hop’s lease.

timeouts

dictionary

The waits each hop’s lease is counted from, in seconds.

peer

integer

The wait for the portals, the role’s cluster_upgrade_peer_timeout; 1800 when unset.

reboot

integer

A reboot’s wait, the role’s cluster_upgrade_reboot_timeout; 43200 when unset.

unblock

integer

The wait for the preflight to clear, the role’s cluster_upgrade_unblock_timeout; 14400 when unset.

wait

integer

Each phase’s wait, the role’s cluster_upgrade_wait_timeout; 3600 when unset.

window

dictionary

Answer only whether the hop’s commits may begin now, in window, and plan nothing.

held

list / elements=string

The hosts the run has already held in this hop, which do not decide the clock.

Default: []

hop

dictionary / required

One of plan.hops.

Attributes

Attribute

Support

Description

check_mode

Support: full

This action does not modify the cluster.

Can run in check mode and return a changed status prediction without modifying the cluster.

diff_mode

Support: none

This action does not modify the cluster.

Will return details on what has changed, or would change in check mode, when in diff mode.

idempotent

Support: full

This action does not modify the cluster.

When run twice in a row outside check mode with the same arguments, the second run reports no change.

This assumes that nothing else changed the cluster in between.

Notes

Note

  • API: none.

  • Registers: G-UPGRADE-PATH, an upgrade path cannot be read ahead; G-UPGRADE-LETTER, a letter release as a source; G-UPGRADE-COUNT, a reboot count checked late; G-UPGRADE-RECORD, the commit records it decides; G-UPGRADE-LICENSE, the unlicensed edge it warns about.

Examples

# edge01_connection holds the connection options, such as {api_host: edge01.example.com, api_username: admin,
# api_password: "{{ vault_edge01_password }}"}.
# upgrade_plan takes no connection options. In a play over many hosts every host computes the same plan, so run_once
# keeps it to one run, and delegate_to: localhost puts that run on the controller.
- name: Read an edge's version and upgrade status for the plan
  # The plan sends nothing; these reads are its input. The upgrade subset gives the status and the protection.
  qumulo.cluster.cluster_info:
    gather_subset: [node, version, upgrade]
  module_defaults:
    group/qumulo.cluster.qumulo: "{{ edge01_connection }}"
  register: edge01_info

- name: Plan the run from every inventory host
  qumulo.cluster.upgrade_plan:
    hosts:
      - name: edge01
        cluster_uuid: "{{ edge01_info.cluster.cluster_id }}"
        version: "{{ edge01_info.cluster.version }}"
        build: "{{ edge01_info.cluster.build_id }}"
        status: "{{ edge01_info.cluster.upgrade.status }}"
        protection: "{{ edge01_info.cluster.upgrade.protection }}"
        cluster_kind: edge
        target: "7.11.0"
        images: "{{ hostvars['edge01'].qumulo_upgrade_images | qumulo.cluster.redact_images }}"
    # The play targets every inventory host, so its hosts are the run's --limit.
    limit: "{{ ansible_play_hosts_all }}"
    forks: "{{ ansible_forks }}"
  check_mode: true
  run_once: true
  register: upgrade_plan_result

- name: Plan a host that commits only inside a maintenance window
  # Reads edge01_info from the task that registered it above.
  qumulo.cluster.upgrade_plan:
    hosts:
      - name: edge01
        cluster_uuid: "{{ edge01_info.cluster.cluster_id }}"
        version: "{{ edge01_info.cluster.version }}"
        build: "{{ edge01_info.cluster.build_id }}"
        status: "{{ edge01_info.cluster.upgrade.status }}"
        protection: "{{ edge01_info.cluster.upgrade.protection }}"
        cluster_kind: edge
        target: "7.11.0"
        images: "{{ hostvars['edge01'].qumulo_upgrade_images | qumulo.cluster.redact_images }}"
        maintenance_windows:
          - start_hour: 22
            start_minute: 0
            end_hour: 4
            end_minute: 0
            on_days: [SAT, SUN]
        window_timezone: America/Los_Angeles
    now: "2026-11-04T17:00:00Z"
  run_once: true
  register: upgrade_plan_windowed

- name: Ask whether the first hop's commits may begin now
  # Needs upgrade_plan_windowed from the plan above, whose host declares a maintenance window. Against a hop that declares
  # none, the answer is always declared false and inside true.
  qumulo.cluster.upgrade_plan:
    window:
      hop: "{{ upgrade_plan_windowed.plan.hops[0] }}"
      held: []
  run_once: true
  register: upgrade_plan_window

- name: Keep the plan's refusals when it refuses
  # Reads edge01_info from the task that registered it above.
  qumulo.cluster.upgrade_plan:
    hosts:
      - name: edge01
        cluster_uuid: "{{ edge01_info.cluster.cluster_id }}"
        version: "{{ edge01_info.cluster.version }}"
        build: "{{ edge01_info.cluster.build_id }}"
        status: "{{ edge01_info.cluster.upgrade.status }}"
        protection: "{{ edge01_info.cluster.upgrade.protection }}"
        cluster_kind: edge
        target: "7.11.0"
        images: "{{ hostvars['edge01'].qumulo_upgrade_images | qumulo.cluster.redact_images }}"
  run_once: true
  register: upgrade_plan_refused
  failed_when: false

- name: Show each refusal the plan made
  # The list is empty when the plan did not refuse.
  ansible.builtin.debug:
    msg: "{{ item.host }} {{ item.code }}: {{ item.message }}"
  loop: "{{ upgrade_plan_refused.plan.refusals | default([]) }}"
  run_once: true

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

plan

dictionary

The run’s plan; on a refusal, its refusals and warnings, and no hops.

Returned: without window, and on a failure from a refusal

Sample: {"hops": [{"components": {}, "forks_warning": null, "hosts": {"edge01": {"build": null, "holds": ["edge01"], "image_index": 0, "image_redacted": "https://images.example.com/qumulo/qumulo_core_7.11.0.qimg", "kind": "on-prem", "reboot": "rolling", "reboots_only": false, "round": 1, "step": 0, "unit": "edge01", "version": "7.11.0", "wave": null}}, "lease": 151200, "moves": ["edge01"], "notes": [], "number": 1, "release": "7.11.0", "steps": [{"hosts": ["edge01"], "round": 1, "wave": null}], "units": [{"follows": [], "name": "edge01", "reason": "a cluster in no portal component the hop moves", "round": 1, "waves": [["edge01"]]}], "windows": {}}], "lock_hosts": {"edge01": ["edge01"]}, "notes": [], "records": {"drop": [], "retire": []}, "refusals": [], "skipped": [], "warnings": []}

hops

list / elements=dictionary

The hops in order, each with its number, release, lease in seconds, the hosts it moves, its portal components with their split and closes marks, its commit steps, its units, its hosts, its windows and its notes.

Each hop’s forks_warning says that forks, or throttle, is below the hop’s size or its largest commit step, for the qumulo.cluster.cluster_upgrade role to print, or is null. It is not among plan.warnings.

Each of hosts gives the image_index of the host’s entry in its own qumulo_upgrade_images, the entry’s image_redacted, version, build and kind, the reboot mode, its unit, round, wave and step, the hosts a failure of it holds, and reboots_only for a host on the target build still rebooting.

Returned: success

lock_hosts

dictionary

Each host the run locks, with the hosts its lock protects, itself and its replication targets.

Returned: success

notes

list / elements=dictionary

What the plan noticed, each {host, message}.

Returned: success

records

dictionary

The commit records to retire and to drop, each {host, path, digest, line}. Nothing is removed here.

Returned: success

refusals

list / elements=dictionary

Each refusal, {host, code, message}.

Returned: success

skipped

list / elements=string

The hosts already at their target.

Returned: success

warnings

list / elements=dictionary

Each warning, {code, host, message}.

Returned: success

window

dictionary

Whether the hop’s commits may begin now.

declared is false when no host the hop commits declares a window. inside is false when one is outside. next_open is the UTC time every such host is next inside, and outside_hosts the hosts outside.

held is the hosts the window holds, lines the split components that commit to close their split, and message the refusal for the held hosts, or null.

Returned: with window

Sample: {"declared": true, "held": ["edge01"], "inside": false, "lines": [], "message": "edge01 were not committed: the hop to 7.11.0 is outside their maintenance window, which next opens 2026-11-07 22:00 America/Los_Angeles. They stay prepared. Run the upgrade again inside the window.", "next_open": "2026-11-08T06:00:00Z", "outside_hosts": ["edge01"]}
