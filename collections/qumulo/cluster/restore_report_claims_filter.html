qumulo.cluster.restore_report_claims filter – The rebuild report’s claim on a host’s relationships, read on the controller

Note

This filter plugin is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.restore_report_claims.

New in qumulo.cluster 0.1.0

  • Synopsis

  • Input

  • Examples

  • Return Value

Synopsis

  • Reads the host’s directory under the artifact directory, <artifact dir>/<host>, on the controller.

  • The newest rebuild-*.yml there by name claims each key of its held list that no restore stamp naming that report retires. A stamp is restore/done-<digest>.yml, named by the digest of qumulo.cluster.restore_key_hash, of format 1, whose report is the newest report’s file name.

  • A report with no held list, as one written before the restore, claims nothing, and so do no report, a report that cannot be read as YAML, a held entry without a key of the restore record’s shape, and an empty or missing directory.

  • A directory that cannot be listed fails the filter, naming it.

Input

This describes the input of the filter, the value before | qumulo.cluster.restore_report_claims.

Parameter

Comments

Input

string / required

The host’s directory under the artifact directory, or an empty string for a host with none.

Examples

- name: Show the rebuild report's claim on edge01's relationships
  vars:
    artifact_dir: "{{ ansible_inventory_sources | qumulo.cluster.artifact_dir(inventory_file | default('')) }}"
  ansible.builtin.debug:
    msg: "{{ (artifact_dir ~ '/edge01') | qumulo.cluster.restore_report_claims }}"

- name: List the relationships the newest rebuild report still holds for edge01
  vars:
    artifact_dir: "{{ ansible_inventory_sources | qumulo.cluster.artifact_dir(inventory_file | default('')) }}"
    edge01_claims: "{{ (artifact_dir ~ '/edge01') | qumulo.cluster.restore_report_claims }}"
  ansible.builtin.debug:
    msg: "{{ edge01_claims.claimed | map(attribute='source_path') | list }}"
  when: edge01_claims.report is not none

- name: Fail when the newest rebuild report of this host still holds a relationship
  vars:
    artifact_dir: "{{ ansible_inventory_sources | qumulo.cluster.artifact_dir(inventory_file | default('')) }}"
    claims: "{{ (artifact_dir ~ '/' ~ inventory_hostname) | qumulo.cluster.restore_report_claims }}"
  ansible.builtin.assert:
    that: claims.claimed | length == 0
    fail_msg: A relationship of {{ inventory_hostname }} is still held by its rebuild report.

Return Value

Key

Description

Return value

dictionary

The claim.

Returned: always

claimed

list / elements=dictionary

The claimed keys, each with source_path, target_host, target_cluster_uuid and target_path, normalized: each path without its trailing slash, and the target cluster UUID in lower case.

Returned: success

Sample: [{"source_path": "/projects", "target_cluster_uuid": "7d4a2e10-3c8b-4f5a-9b6e-1a2b3c4d5e6f", "target_host": "hub01", "target_path": "/replicas/edge01"}]

report

string

The newest report’s file name, or null when there is none.

Returned: success

Sample: "rebuild-20261102T100000Z.yml"

stamped

list / elements=string

The key hashes of the restore stamps of format 1 that name the newest report, each relationship restored or paired since that rebuild; empty when there is no report.

Returned: success

Sample: ["c6f21a2d2f429154980c601dcefa44cce45d276f639aff197d40598dc1ef34dc"]
