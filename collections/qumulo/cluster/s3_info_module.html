qumulo.cluster.s3_info module – Read a Qumulo cluster’s S3 settings, buckets, bucket policies and access keys

Note

This module is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.s3_info.

New in qumulo.cluster 0.1.0

  • Synopsis

  • Parameters

  • Attributes

  • Notes

  • Examples

  • Return Values

Synopsis

  • Gathers the S3 configuration of one cluster, and changes nothing.

  • The settings, each bucket and each policy come back in the option shape of qumulo.cluster.s3_settings, qumulo.cluster.s3_bucket and qumulo.cluster.s3_bucket_policy. Each key comes back with its user, its id and when it was made.

  • No key’s secret is returned; the cluster returns a secret only when it makes the key (G-S3-KEY).

Parameters

Parameter

Comments

api_host

string / required

Address or name of the Qumulo cluster’s REST API.

An IPv6 address is given bare, as fd00::5; the URL puts it in brackets.

If not set, the value of the QUMULO_API_HOST environment variable is used.

api_password

string

Password of api_username.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_PASSWORD environment variable is used.

api_port

integer

TCP port of the REST API.

If not set, the value of the QUMULO_API_PORT environment variable is used.

Default: 8000

api_token

string

An access token, sent in place of logging in.

An access token is bound to one cluster and does not survive a rebuild.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_TOKEN environment variable is used.

api_username

string

User that logs in with api_password.

If not set, the value of the QUMULO_API_USERNAME environment variable is used.

Default: "admin"

ca_path

path

PEM file of the certificate authority that signed the cluster’s certificate.

On Python 3.13 and later this must be a CA certificate, with basic constraints.

A bare self-signed leaf certificate cannot be pinned here on Python 3.13 and later; such a cluster is reached only with validate_certs=false.

If not set, the value of the QUMULO_CA_PATH environment variable is used.

expected_cluster_uuid

string

The UUID the cluster at api_host must have.

Before the first credentials are sent, the module reads the cluster’s UUID from GET /v1/node/state, which needs no login, and fails when it differs, so that no credentials are sent to the wrong cluster. On a mismatch the task fails with live_cluster_uuid and expected_cluster_uuid in its result.

An empty value disables this identity guard, and a module that logs in warns.

If not set, the value of the QUMULO_EXPECTED_CLUSTER_UUID environment variable is used.

gather_subset

list / elements=string

The subsets of facts to gather. all gathers every subset.

Choices:

  • "all" ← (default)

  • "settings"

  • "buckets"

  • "policies"

  • "access_keys"

Default: ["all"]

request_timeout

integer

Seconds to wait for one HTTP response.

If not set, the value of the QUMULO_REQUEST_TIMEOUT environment variable is used.

Default: 60

retry_timeout

integer

Seconds to keep retrying a request that is safe to resend, after a lost connection or an HTTP 502, 503 or 504.

If not set, the value of the QUMULO_RETRY_TIMEOUT environment variable is used.

Default: 300

validate_certs

boolean

Verify the cluster’s TLS certificate.

If not set, the value of the QUMULO_VALIDATE_CERTS environment variable is used.

Choices:

  • false

  • true ← (default)

Notes

Note

  • API: settings GET /v1/s3/settings; buckets GET /v1/s3/buckets/; policies GET /v1/s3/buckets/ and each bucket’s GET /v1/s3/buckets/{name}/policy; access_keys GET /v1/s3/access-keys/, paged.

Examples

# These tasks take api_host and a credential from module_defaults for group/qumulo.cluster.qumulo.
- name: Read all of the cluster's S3 configuration
  qumulo.cluster.s3_info:
  register: s3

- name: Read the S3 server settings only
  qumulo.cluster.s3_info:
    gather_subset: [settings]
  register: s3_server

- name: Say whether the S3 server is on
  ansible.builtin.debug:
    msg: "S3 is {{ 'on' if s3_server.s3.settings.enabled else 'off' }}, HTTPS only: {{ s3_server.s3.settings.secure }}"

- name: Read the buckets and the keys
  qumulo.cluster.s3_info:
    gather_subset: [buckets, access_keys]
  register: s3_inventory

- name: Check that no bucket lies outside /data
  ansible.builtin.assert:
    that: s3_inventory.s3.buckets | rejectattr('path', 'match', '^/data(/|$)') | list == []

- name: Find the ids of the keys the backup service holds
  ansible.builtin.set_fact:
    backup_key_ids: "{{ s3_inventory.s3.access_keys | selectattr('user', 'equalto', 'local:svc-backup') | map(attribute='access_key_id') | list }}"

- name: Find the buckets that have no policy
  qumulo.cluster.s3_info:
    gather_subset: [buckets, policies]
  register: s3_policies

- name: List the buckets without a policy
  ansible.builtin.debug:
    msg: "{{ s3_policies.s3.buckets | map(attribute='name') | difference(s3_policies.s3.policies | map(attribute='bucket')) | list }}"

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

s3

dictionary

The gathered facts. Each key is present only when its subset was gathered.

Returned: always

Sample: {"access_keys": [{"access_key_id": "00000000000003e8b5a2", "creation_time": "2026-11-02T01:58:32Z", "user": "local:svc-backup"}], "buckets": [{"default_retention": null, "name": "photos", "object_lock": false, "path": "/data/photos", "versioning": "Enabled"}], "policies": [{"bucket": "photos", "policy": {"Statement": [{"Action": ["s3:GetObject"], "Effect": "Allow", "Principal": {"Qumulo": ["world:Everyone"]}}]}}], "settings": {"base_path": "/", "enabled": true, "multipart_upload_expiry_interval": "1weeks", "secure": true}}

list / elements=dictionary

Every key, with its user and id and when it was made, never its secret.

Returned: success

The key’s id.

Returned: success

When the cluster made the key.

Returned: success

The key’s owner, as a trustee.

Returned: success

Every bucket, in the option shape of qumulo.cluster.s3_bucket.

Returned: success

default_retention

dictionary

How long a locked bucket locks each new object, by default; null when there is none.

Returned: success

units

string

The unit of value.

Returned: success

value

integer

The number of units.

Returned: success

name

string

The bucket’s name.

Returned: success

object_lock

boolean

Whether objects can be locked.

Returned: success

path

string

The directory the bucket serves.

Returned: success

versioning

string

Unversioned, Enabled or Suspended.

Returned: success

policies

list / elements=dictionary

The policy of each bucket that has one, in the option shape of qumulo.cluster.s3_bucket_policy.

A bare AD name must be given a trustee prefix before the entry is passed to qumulo.cluster.s3_bucket_policy.

Returned: success

bucket

string

The bucket’s name.

Returned: success

policy

dictionary

The policy document as the cluster reads it back.

Principals are as the cluster names them, such as sid:S-1-5-88-1-1000 for uid:1000, ad:Authenticated Users for Authenticated Users, the bare File Owner for File Owner, or a bare AD name.

Returned: success

settings

dictionary

The S3 server settings, in the option shape of qumulo.cluster.s3_settings.

Returned: success

base_path

string

The directory under which the cluster puts a bucket created without a path.

Returned: success

enabled

boolean

Whether the S3 server answers requests.

Returned: success

multipart_upload_expiry_interval

string

How long an unfinished multipart upload is kept, in the form the cluster reads it back, or never.

Returned: success

secure

boolean

Whether the S3 server accepts only HTTPS connections.

Returned: success
