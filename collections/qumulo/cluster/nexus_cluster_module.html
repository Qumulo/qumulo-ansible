qumulo.cluster.nexus_cluster module – Retire a cluster in Qumulo’s Nexus service

Note

This module is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.nexus_cluster.

New in qumulo.cluster 0.1.0

Synopsis

  • Marks a cluster UUID as decommissioned in Nexus. The cluster is found by cluster_uuid.

  • A cluster Nexus already lists as decommissioned, or does not list at all, is left alone.

  • The connection options name a cluster too. When that cluster is the one being retired, the module first checks that its Nexus registration has been removed (qumulo.cluster.nexus_registration state=absent).

Parameters

Parameter

Comments

allow_connected

boolean

Retire the cluster even while Nexus reports it connected. Without it the module fails for a connected cluster.

Nexus may keep reporting a cluster connected for a short while after its registration was removed.

Choices:

  • false ← (default)

  • true

api_host

string / required

Address or name of the Qumulo cluster’s REST API.

An IPv6 address is given bare, as fd00::5; the URL puts it in brackets.

If not set, the value of the QUMULO_API_HOST environment variable is used.

api_password

string

Password of api_username.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_PASSWORD environment variable is used.

api_port

integer

TCP port of the REST API.

If not set, the value of the QUMULO_API_PORT environment variable is used.

Default: 8000

api_token

string

An access token, sent in place of logging in.

An access token is bound to one cluster and does not survive a rebuild.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_TOKEN environment variable is used.

api_username

string

User that logs in with api_password.

If not set, the value of the QUMULO_API_USERNAME environment variable is used.

Default: "admin"

ca_path

path

PEM file of the certificate authority that signed the cluster’s certificate.

On Python 3.13 and later this must be a CA certificate, with basic constraints.

A bare self-signed leaf certificate cannot be pinned here on Python 3.13 and later; such a cluster is reached only with validate_certs=false.

If not set, the value of the QUMULO_CA_PATH environment variable is used.

cluster_uuid

string / required

The UUID of the cluster to retire in Nexus.

expected_cluster_uuid

string

The UUID the cluster at api_host must have.

Before the first credentials are sent, the module reads the cluster’s UUID from GET /v1/node/state, which needs no login, and fails when it differs, so that no credentials are sent to the wrong cluster. On a mismatch the task fails with live_cluster_uuid and expected_cluster_uuid in its result.

An empty value disables this identity guard, and a module that logs in warns.

If not set, the value of the QUMULO_EXPECTED_CLUSTER_UUID environment variable is used.

nexus_api_token

string

A Nexus user’s API token, sent to Nexus as a bearer token. It is never sent to the cluster.

What the token may do depends on the user’s role in the Nexus organization; each module says which calls it makes.

If not set, the value of the QUMULO_NEXUS_API_TOKEN environment variable is used.

nexus_api_url

string

Base URL of the Nexus API. Only https URLs are accepted, and the certificate is always verified.

If not set, the value of the QUMULO_NEXUS_API_URL environment variable is used.

Default: "https://api.nexus.qumulo.com"

request_timeout

integer

Seconds to wait for one HTTP response.

If not set, the value of the QUMULO_REQUEST_TIMEOUT environment variable is used.

Default: 60

retry_timeout

integer

Seconds to keep retrying a request that is safe to resend, after a lost connection or an HTTP 502, 503 or 504.

If not set, the value of the QUMULO_RETRY_TIMEOUT environment variable is used.

Default: 300

state

string

decommissioned retires the cluster in Nexus. Nexus offers no way back.

Choices:

  • "decommissioned" ← (default)

validate_certs

boolean

Verify the cluster’s TLS certificate.

If not set, the value of the QUMULO_VALIDATE_CERTS environment variable is used.

Choices:

  • false

  • true ← (default)

Attributes

Attribute

Support

Description

action_group

Action group: qumulo.cluster.qumulo

Use group/qumulo.cluster.qumulo in module_defaults to set the connection options for this module.

check_mode

Support: full

Check mode reads Nexus and the cluster, as a real run does, and changes nothing.

Can run in check mode and return a changed status prediction without modifying the cluster.

diff_mode

Support: full

Will return details on what has changed, or would change in check mode, when in diff mode.

idempotent

Support: full

When run twice in a row outside check mode with the same arguments, the second run reports no change.

This assumes that nothing else changed the cluster in between.

Notes

Note

  • API: Nexus GET /api/v1/clusters?cluster_uuid=, GET /api/v1/clusters/<uuid>/fleet/connection and PATCH /api/v1/clusters/<uuid>/status; when cluster_uuid is the cluster at api_host, GET /v1/node/state and GET /v1/nexus/registration on it.

  • nexus_api_token is required, and needs a Nexus role that may decommission clusters in the cluster’s organization.

  • The module reads the cluster’s status back after retiring it. When Nexus lists the cluster without a status, or no longer lists it, the module fails and reports a change, because it cannot show that the cluster is retired.

  • Retiring does not stop a cluster that still has the UUID. Given a new join key, it registers again, and Nexus keeps listing it as decommissioned (QUIRK-018).

  • The connection options must name a reachable cluster and its credentials even when cluster_uuid belongs to a cluster that no longer exists (G-NEXUS-RETIRE). After a rebuild, run it against the new edge.

Examples

# These tasks carry no connection options. Set them once for the play with module_defaults for
# group/qumulo.cluster.qumulo, or in the QUMULO_* environment variables. They must name a reachable cluster, such as
# the rebuilt edge, although the cluster that had the retired UUID no longer exists (G-NEXUS-RETIRE).
- name: Preview retiring the UUID an edge had before its rebuild
  qumulo.cluster.nexus_cluster:
    cluster_uuid: 0b6d2a41-77c1-4b8e-9a51-2f0e6c3d9e02
    nexus_api_token: "{{ vault_nexus_api_token }}"
  check_mode: true
  diff: true
  register: retire_preview

- name: Show the cluster as Nexus would list it
  ansible.builtin.debug:
    var: retire_preview.nexus_cluster

# Nexus offers no way back. Retire only a UUID that no cluster will use again, such as the one an edge had before a
# rebuild gave it a new one: a cluster given a new join key registers again under the same UUID.
- name: Retire the UUID an edge had before its rebuild
  qumulo.cluster.nexus_cluster:
    cluster_uuid: 0b6d2a41-77c1-4b8e-9a51-2f0e6c3d9e02
    nexus_api_token: "{{ vault_nexus_api_token }}"

- name: Retire several old UUIDs
  qumulo.cluster.nexus_cluster:
    cluster_uuid: "{{ item }}"
    nexus_api_token: "{{ vault_nexus_api_token }}"
  loop:
    - 0b6d2a41-77c1-4b8e-9a51-2f0e6c3d9e02
    - 5f1c8e90-3a2b-4d67-8c14-b7a9e0d2f6a3

# A cluster that still connects is usually still in use. Nexus may report one connected for a short while after its
# registration was removed.
- name: Retire the old UUID although Nexus still reports it connected
  qumulo.cluster.nexus_cluster:
    cluster_uuid: 0b6d2a41-77c1-4b8e-9a51-2f0e6c3d9e02
    nexus_api_token: "{{ vault_nexus_api_token }}"
    allow_connected: true

# Retire a cluster that is about to be destroyed. Its Nexus registration must be removed first, and Nexus may report
# it connected for a short while after that, hence allow_connected.
- name: Remove a cluster's registration and retire it in Nexus before destroying it
  block:
    - name: Read the cluster's UUID
      qumulo.cluster.cluster_info:
        gather_subset: [node]
      register: this_cluster

    - name: Remove the cluster's Nexus registration
      qumulo.cluster.nexus_registration:
        state: absent

    - name: Retire the cluster's UUID in Nexus
      qumulo.cluster.nexus_cluster:
        cluster_uuid: "{{ this_cluster.cluster.cluster_id }}"
        nexus_api_token: "{{ vault_nexus_api_token }}"
        allow_connected: true

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

nexus_cluster

dictionary

The cluster as Nexus lists it after the task, or in check mode as it would list it, or null when Nexus does not list it.

Returned: always

Sample: {"cluster_name": "edge01", "cluster_uuid": "0b6d2a41-77c1-4b8e-9a51-2f0e6c3d9e02", "connected": false, "status": "DECOMMISSIONED"}

cluster_name

string

The cluster’s name in Nexus.

Returned: success

cluster_uuid

string

The cluster’s UUID.

Returned: success

connected

boolean

Whether Nexus reported the cluster connected; null when the module did not ask, as for a cluster already decommissioned.

Returned: success

status

string

The cluster’s status in Nexus, such as DECOMMISSIONED, or null when Nexus does not report it.

Returned: success

notes

list / elements=string

Why the module did or did not act, when that is not plain from the result.

Returned: when there is something to say

Sample: ["Nexus has no cluster 0b6d2a41-77c1-4b8e-9a51-2f0e6c3d9e02, so there is nothing to retire"]
