qumulo.cluster.cluster_info module – Read a Qumulo cluster’s identity, version, license, capacity and product type

Note

This module is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.cluster_info.

New in qumulo.cluster 0.1.0

Synopsis

  • Gathers facts about one Qumulo cluster, one or two GET requests per subset, and changes nothing.

  • On a node that is not yet part of a cluster (state UNCONFIGURED) no login is possible, so only the node and version subsets, which need no login, are gathered. The others are listed in unavailable_subsets, and the module warns.

  • A subset that this cluster’s product type or version does not offer is listed in unavailable_subsets with the reason, and the module does not fail.

Parameters

Parameter

Comments

api_host

string / required

Address or name of the Qumulo cluster’s REST API.

An IPv6 address is given bare, as fd00::5; the URL puts it in brackets.

If not set, the value of the QUMULO_API_HOST environment variable is used.

api_password

string

Password of api_username.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_PASSWORD environment variable is used.

api_port

integer

TCP port of the REST API.

If not set, the value of the QUMULO_API_PORT environment variable is used.

Default: 8000

api_token

string

An access token, sent in place of logging in.

An access token is bound to one cluster and does not survive a rebuild.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_TOKEN environment variable is used.

api_username

string

User that logs in with api_password.

If not set, the value of the QUMULO_API_USERNAME environment variable is used.

Default: "admin"

ca_path

path

PEM file of the certificate authority that signed the cluster’s certificate.

On Python 3.13 and later this must be a CA certificate, with basic constraints.

A bare self-signed leaf certificate cannot be pinned here on Python 3.13 and later; such a cluster is reached only with validate_certs=false.

If not set, the value of the QUMULO_CA_PATH environment variable is used.

expected_cluster_uuid

string

The UUID the cluster at api_host must have.

Before the first credentials are sent, the module reads the cluster’s UUID from GET /v1/node/state, which needs no login, and fails when it differs, so that no credentials are sent to the wrong cluster. On a mismatch the task fails with live_cluster_uuid and expected_cluster_uuid in its result.

An empty value disables this identity guard, and a module that logs in warns.

If not set, the value of the QUMULO_EXPECTED_CLUSTER_UUID environment variable is used.

gather_subset

list / elements=string

The subsets of facts to gather. Each is returned under cluster.

node the cluster’s UUID and the node’s state, version the Qumulo Core release and build, settings the cluster’s name, license the license, capacity the capacity clamp, product the product type, filesystem the file system’s sizes.

nodes the nodes, portals the number of spoke and hub portals, protection the protection status, upgrade the upgrade’s state and upgrade_blocked the upgrade preflight.

all gathers every subset, adding nodes, portals, protection, upgrade and upgrade_blocked to the default.

node and version need no login. Every other subset logs in.

Choices:

  • "all"

  • "node" ← (default)

  • "version" ← (default)

  • "settings" ← (default)

  • "license" ← (default)

  • "capacity" ← (default)

  • "product" ← (default)

  • "filesystem" ← (default)

  • "nodes"

  • "portals"

  • "protection"

  • "upgrade"

  • "upgrade_blocked"

Default: ["node", "version", "settings", "license", "capacity", "product", "filesystem"]

request_timeout

integer

Seconds to wait for one HTTP response.

If not set, the value of the QUMULO_REQUEST_TIMEOUT environment variable is used.

Default: 60

retry_timeout

integer

Seconds to keep retrying a request that is safe to resend, after a lost connection or an HTTP 502, 503 or 504.

If not set, the value of the QUMULO_RETRY_TIMEOUT environment variable is used.

Default: 300

validate_certs

boolean

Verify the cluster’s TLS certificate.

If not set, the value of the QUMULO_VALIDATE_CERTS environment variable is used.

Choices:

  • false

  • true ← (default)

Notes

Note

  • API: node GET /v1/node/state and version GET /v1/version, both without login; settings GET /v1/cluster/settings; license GET /v1/license/status and /v1/license/enforcement; capacity GET /v1/capacity/clamp; product GET /v2/metrics/endpoints/default/data as text/plain; filesystem GET /v1/file-system; nodes GET /v1/cluster/nodes/; portals GET /v2/portal/spokes/ and /v2/portal/hubs/; protection GET /v1/cluster/protection/status; upgrade GET /v3/upgrade/status, /v2/upgrade/blocked, /v1/shutdown/reboot/status and /v1/cluster/protection/status, and on an object-backed cluster /v1/cluster/nodes/; upgrade_blocked GET /v2/upgrade/blocked.

  • The product type has no REST endpoint of its own. It is read from the labels of the qumulo_info sample on the cluster’s metrics endpoint.

  • A route this cluster does not offer (HTTP 404, 405, 406 or 501) makes its subset unavailable. Any other error, such as a missing RBAC privilege, fails the module.

Examples

# These tasks carry no connection options. Set them once for the play with module_defaults for
# group/qumulo.cluster.qumulo, or in the QUMULO_* environment variables.
- name: Read the default facts
  qumulo.cluster.cluster_info:
  register: info

- name: Show the cluster's name, release and license state
  ansible.builtin.debug:
    msg: "{{ info.cluster.cluster_name }} runs Qumulo Core {{ info.cluster.version }}, license {{ info.cluster.license.state }}"

- name: Stop unless this is an unprotected edge
  ansible.builtin.assert:
    that: info.cluster.product.cluster_type == 'unprotected_edge'

- name: Read the node's UUID and state without logging in
  qumulo.cluster.cluster_info:
    gather_subset: [node, version]
  register: node_info

- name: Stop unless the node belongs to a cluster
  ansible.builtin.assert:
    that: node_info.cluster.cluster_id is not none
    fail_msg: "The node is {{ node_info.cluster.state }} and belongs to no cluster yet."

- name: Read the license and when it expires
  qumulo.cluster.cluster_info:
    gather_subset: [license]
  register: license_info

- name: Show when the license expires
  ansible.builtin.debug:
    var: license_info.cluster.license.expiration_date

- name: Read the nodes of the cluster
  qumulo.cluster.cluster_info:
    gather_subset: [nodes]
  register: nodes_info

- name: Show how many nodes the cluster has
  ansible.builtin.debug:
    var: nodes_info.cluster.node_count

- name: Read whether an upgrade is idle and unblocked
  qumulo.cluster.cluster_info:
    gather_subset: [upgrade]
  register: upgrade_info

- name: Stop unless the cluster is ready for an upgrade
  ansible.builtin.assert:
    that:
      - upgrade_info.cluster.upgrade.status.state == 'UPGRADE_STATE_IDLE'
      - not upgrade_info.cluster.upgrade.blocked.is_blocked

- name: Read everything, including nodes and portals
  qumulo.cluster.cluster_info:
    gather_subset: [all]
  register: everything

- name: Show the subsets this cluster could not answer
  ansible.builtin.debug:
    var: everything.unavailable_subsets | default({})

dictionary

The protection status from the protection subset.

On an object-backed cluster only protection_system_type is returned.

Returned: success

Sample: {"blocks_per_stripe": 1, "data_blocks_per_stripe": 1, "max_drive_failures": 0, "max_drive_spares": 0, "max_node_failures": 0, "pending_configuration": null, "protection_system_type": "PROTECTION_SYSTEM_TYPE_EC", "remaining_drive_failures": 0, "remaining_node_failures": 0}

state

string

The node’s state, such as ACTIVE or UNCONFIGURED. From the node subset.

Returned: success

Sample: "ACTIVE"

upgrade

dictionary

The upgrade’s state, from the upgrade subset.

status is GET /v3/upgrade/status‘s answer, never the deprecated v2 status, which reads REBOOTING as IDLE (QUIRK-090), with any URL in settings.install_path or error_info stripped of its query string and user information. blocked is the upgrade preflight, and reboot the reboot manager’s status.

The subset, and so all, reads /v1/shutdown/reboot/status once per gather, and each such read asks every node for its boot identity.

protection gives the node tolerances on every cluster type, including an object-backed one, where the protection subset returns only protection_system_type. configured_node_failures is max_node_failures on an erasure-coded cluster, and on an object-backed one 0 below three nodes and 1 from three.

Returned: success

Sample: {"blocked": {"blocked_reason": "", "cluster_degraded": false, "is_blocked": false}, "protection": {"configured_node_failures": 0, "remaining_node_failures": 0, "type": "PROTECTION_SYSTEM_TYPE_EC"}, "reboot": {"error_message": null, "rebooted_node_count": 0, "rolling": false, "state": "REBOOT_IDLE", "total_node_count": 0, "upgrade_initiated": false}, "status": {"error_info": null, "progress": null, "settings": null, "state": "UPGRADE_STATE_IDLE"}}

upgrade_blocked

dictionary

The upgrade preflight, GET /v2/upgrade/blocked‘s answer, from the upgrade_blocked subset, which reads nothing else. Unlike upgrade, it does not read the reboot status.

Returned: success

Sample: {"blocked_reason": "", "cluster_degraded": false, "is_blocked": false}

version

string

The Qumulo Core release, dotted. From the version subset.

Returned: success

Sample: "7.10.3"

unavailable_subsets

dictionary

Each requested subset this cluster could not answer, with the reason.

Returned: when a subset was unavailable

Sample: {"portals": "GET /v2/portal/spokes/ failed: HTTP 404 ..."}
