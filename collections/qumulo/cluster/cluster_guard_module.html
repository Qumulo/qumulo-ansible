qumulo.cluster.cluster_guard module – Check that a Qumulo cluster is the one a play expects, and wait until it is ready

Note

This module is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.cluster_guard.

New in qumulo.cluster 0.1.0

Synopsis

  • Reads only, and never reports a change.

  • With mode=match, checks that the cluster at api_host has the UUID expected_cluster_uuid before any credentials are sent, then waits until the cluster is ready to serve requests. Every qumulo.cluster module checks the UUID before it logs in; this module adds the wait.

  • With mode=rebuilt, checks that the cluster was rebuilt and holds nothing yet. It passes for a node that is UNCONFIGURED, or for an ACTIVE cluster that meets every condition below; any other cluster fails, and the message names the first condition it does not meet.

  • The ACTIVE cluster’s UUID is new_cluster_uuid. This is checked before any credentials are sent, and a node that belongs to any other cluster fails at once, whatever its state.

  • The ACTIVE cluster is an unprotected edge, according to the cluster_type label of its qumulo_info metric.

  • The ACTIVE cluster’s name is cluster_name.

  • The ACTIVE cluster has no spoke portals and no hub portals.

  • The ACTIVE cluster has no SMB share other than the factory Files share, and no NFS export other than the factory / export.

Parameters

Parameter

Comments

api_host

string / required

Address or name of the Qumulo cluster’s REST API.

An IPv6 address is given bare, as fd00::5; the URL puts it in brackets.

If not set, the value of the QUMULO_API_HOST environment variable is used.

api_password

string

Password of api_username.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_PASSWORD environment variable is used.

api_port

integer

TCP port of the REST API.

If not set, the value of the QUMULO_API_PORT environment variable is used.

Default: 8000

api_token

string

An access token, sent in place of logging in.

An access token is bound to one cluster and does not survive a rebuild.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_TOKEN environment variable is used.

api_username

string

User that logs in with api_password.

If not set, the value of the QUMULO_API_USERNAME environment variable is used.

Default: "admin"

ca_path

path

PEM file of the certificate authority that signed the cluster’s certificate.

On Python 3.13 and later this must be a CA certificate, with basic constraints.

A bare self-signed leaf certificate cannot be pinned here on Python 3.13 and later; such a cluster is reached only with validate_certs=false.

If not set, the value of the QUMULO_CA_PATH environment variable is used.

cluster_name

string

The name the rebuilt cluster must have when it is ACTIVE. Needed for mode=rebuilt on an ACTIVE cluster.

expected_cluster_uuid

string

The UUID the cluster at api_host must have.

Before the first credentials are sent, the module reads the cluster’s UUID from GET /v1/node/state, which needs no login, and fails when it differs, so that no credentials are sent to the wrong cluster. On a mismatch the task fails with live_cluster_uuid and expected_cluster_uuid in its result.

An empty value disables this identity guard, and a module that logs in warns.

If not set, the value of the QUMULO_EXPECTED_CLUSTER_UUID environment variable is used.

mode

string

match checks that the cluster is the one in expected_cluster_uuid, which must be set; an empty value fails.

rebuilt checks that the cluster is newly formed and empty. expected_cluster_uuid is not used.

Choices:

  • "match" ← (default)

  • "rebuilt"

new_cluster_uuid

string

The UUID the rebuilt cluster must have when it is ACTIVE. Needed for mode=rebuilt on an ACTIVE cluster.

request_timeout

integer

Seconds to wait for one HTTP response.

If not set, the value of the QUMULO_REQUEST_TIMEOUT environment variable is used.

Default: 60

retry_timeout

integer

Seconds to keep retrying a request that is safe to resend, after a lost connection or an HTTP 502, 503 or 504.

If not set, the value of the QUMULO_RETRY_TIMEOUT environment variable is used.

Default: 300

validate_certs

boolean

Verify the cluster’s TLS certificate.

If not set, the value of the QUMULO_VALIDATE_CERTS environment variable is used.

Choices:

  • false

  • true ← (default)

wait

boolean

Wait until the cluster is ready.

It is ready when its node state is ACTIVE, a login succeeds, and the attributes of the root directory can be read. With mode=rebuilt, a node that is UNCONFIGURED is ready at once.

With false, the node state is read once. mode=match then checks only the UUID and logs in to nothing, and mode=rebuilt fails for a node that is neither UNCONFIGURED nor ACTIVE.

A UUID that is not the expected one fails at once, without waiting.

Choices:

  • false

  • true ← (default)

wait_timeout

integer

Seconds to wait for the cluster to be ready, including while its REST API does not answer.

The wait ends at this deadline even when retry_timeout is longer, though a single attempt can still take up to request_timeout.

Default: 600

This assumes that nothing else changed the cluster in between.

Notes

Note

  • API: GET /v1/node/state (no login), GET /v1/version (no login), GET /v1/files/%2F/info/attributes; mode=rebuilt also GET /v2/metrics/endpoints/default/data, /v1/cluster/settings, /v2/portal/spokes/, /v2/portal/hubs/, /v3/smb/shares/ and /v3/nfs/exports/.

  • The module warns when the cluster runs a Qumulo Core release older than the oldest one this collection is tested against.

Examples

# These tasks carry no connection options. Set them once for the play with module_defaults for
# group/qumulo.cluster.qumulo, or in the QUMULO_* environment variables.
# Run the guard first in a play, before any task that writes.
- name: Stop unless api_host is the expected cluster, and wait until it is ready
  qumulo.cluster.cluster_guard:
    expected_cluster_uuid: "{{ qumulo_cluster_uuid }}"

- name: Wait up to half an hour for a cluster that is still starting
  qumulo.cluster.cluster_guard:
    expected_cluster_uuid: "{{ qumulo_cluster_uuid }}"
    wait_timeout: 1800

- name: Check the cluster's UUID once, without waiting or logging in
  qumulo.cluster.cluster_guard:
    expected_cluster_uuid: "{{ qumulo_cluster_uuid }}"
    wait: false

- name: Record the cluster's state and release
  qumulo.cluster.cluster_guard:
    expected_cluster_uuid: "{{ qumulo_cluster_uuid }}"
  register: guard

- name: Show the cluster's state and release
  ansible.builtin.debug:
    msg: "{{ guard.cluster_id }} is {{ guard.state }} on Qumulo Core {{ guard.version }}"

- name: Before configuring a rebuilt edge, check that it is new and empty
  qumulo.cluster.cluster_guard:
    mode: rebuilt
    new_cluster_uuid: "{{ qumulo_new_cluster_uuid }}"
    cluster_name: "{{ qumulo_cluster_name }}"
  when: qumulo_rebuild | default(false) | bool

- name: Check a rebuilt edge once, without waiting for it
  qumulo.cluster.cluster_guard:
    mode: rebuilt
    new_cluster_uuid: "{{ qumulo_new_cluster_uuid }}"
    cluster_name: "{{ qumulo_cluster_name }}"
    wait: false

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

cluster_id

string

The cluster’s UUID, or null on an UNCONFIGURED node.

Returned: success

Sample: "6f1c2c1e-5c3a-4c56-9d2e-3f8c1b0a7e11"

expected_cluster_uuid

string

The UUID the task expected, from expected_cluster_uuid.

Returned: failure, with mode=match, when the cluster’s UUID is not expected_cluster_uuid

Sample: "6f1c2c1e-5c3a-4c56-9d2e-3f8c1b0a7e11"

live_cluster_uuid

string

The UUID the cluster at api_host reports, or null for an UNCONFIGURED node.

Returned: failure, with mode=match, when the cluster’s UUID is not expected_cluster_uuid

Sample: "9533a9e2-e57a-454f-8aa0-9c77b706b7bd"

state

string

The node’s state, such as ACTIVE or UNCONFIGURED.

Returned: success

Sample: "ACTIVE"

version

string

The Qumulo Core release, dotted.

Returned: success

Sample: "7.10.3"
