qumulo.cluster.filesystem_info module – Read a Qumulo cluster’s file system capacity, root directory and quotas

Note

This module is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.filesystem_info.

New in qumulo.cluster 0.1.0

  • Synopsis

  • Parameters

  • Attributes

  • Notes

  • Examples

  • Return Values

Synopsis

  • Gathers facts about the file system of one cluster, and changes nothing.

  • The root directory comes back in the option shape of qumulo.cluster.directory, and each quota in that of qumulo.cluster.directory_quota with its usage added.

  • With find_files it also looks up paths and file ids, and returns the file each one names. A lookup runs whatever gather_subset lists, and in check mode too, since it changes nothing.

  • A subset the cluster does not offer, or capacity on a node that is not yet part of a cluster, is listed in unavailable_subsets with the reason, and the other subsets are still gathered. On such a node root and quotas fail.

Parameters

Parameter

Comments

api_host

string / required

Address or name of the Qumulo cluster’s REST API.

An IPv6 address is given bare, as fd00::5; the URL puts it in brackets.

If not set, the value of the QUMULO_API_HOST environment variable is used.

api_password

string

Password of api_username.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_PASSWORD environment variable is used.

api_port

integer

TCP port of the REST API.

If not set, the value of the QUMULO_API_PORT environment variable is used.

Default: 8000

api_token

string

An access token, sent in place of logging in.

An access token is bound to one cluster and does not survive a rebuild.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_TOKEN environment variable is used.

api_username

string

User that logs in with api_password.

If not set, the value of the QUMULO_API_USERNAME environment variable is used.

Default: "admin"

ca_path

path

PEM file of the certificate authority that signed the cluster’s certificate.

On Python 3.13 and later this must be a CA certificate, with basic constraints.

A bare self-signed leaf certificate cannot be pinned here on Python 3.13 and later; such a cluster is reached only with validate_certs=false.

If not set, the value of the QUMULO_CA_PATH environment variable is used.

expected_cluster_uuid

string

The UUID the cluster at api_host must have.

Before the first credentials are sent, the module reads the cluster’s UUID from GET /v1/node/state, which needs no login, and fails when it differs, so that no credentials are sent to the wrong cluster. On a mismatch the task fails with live_cluster_uuid and expected_cluster_uuid in its result.

An empty value disables this identity guard, and a module that logs in warns.

If not set, the value of the QUMULO_EXPECTED_CLUSTER_UUID environment variable is used.

find_files

list / elements=string

Paths and file ids to look up, in one list, each answered in filesystem.found_files under the term as given.

A term is an absolute path with no empty, . or .. component, such as /data/projects, or a file id of decimal digits, such as 1003. Any other term, such as a relative path, a path with a .. component or a hex id, fails the task before any request is sent. A trailing slash is accepted.

A term that names no file is not an error; its entry has false in found. That is a path that does not exist, a path that runs through a file, the id of a deleted file or of one never issued, an id of a file system this cluster does not have, and an id the server cannot place (QUIRK-101).

In check mode a file that an earlier task of the same run would create is not there yet, so its term is a miss.

A file id holds only on the cluster that issued it, and only until that cluster is rebuilt. An id from another cluster may name nothing here, or an unrelated file. docs/explanation/state-management.md, under Keys, not ids, says why the collection finds objects by key.

A term given twice is one key and is read once.

Default: []

gather_subset

list / elements=string

The subsets of facts to gather. all gathers every subset.

[] gathers every subset too, unless find_files is given; then only the lookup runs.

capacity is the file system’s sizes, root the root directory and quotas every directory quota.

Choices:

  • "all" ← (default)

  • "capacity"

  • "root"

  • "quotas"

Default: ["all"]

request_timeout

integer

Seconds to wait for one HTTP response.

If not set, the value of the QUMULO_REQUEST_TIMEOUT environment variable is used.

Default: 60

retry_timeout

integer

Seconds to keep retrying a request that is safe to resend, after a lost connection or an HTTP 502, 503 or 504.

If not set, the value of the QUMULO_RETRY_TIMEOUT environment variable is used.

Default: 300

validate_certs

boolean

Verify the cluster’s TLS certificate.

If not set, the value of the QUMULO_VALIDATE_CERTS environment variable is used.

Choices:

  • false

  • true ← (default)

Notes

Note

  • API: capacity GET /v1/file-system, the same facts as the filesystem subset of qumulo.cluster.cluster_info; root GET /v1/files/%2F/info/attributes; quotas GET /v1/files/quotas/status/, paged; find_files GET /v1/files/{ref}/info/attributes, one read for each term, one after another.

  • The read of find_files needs no RBAC privilege; a local user with no role could make it on Qumulo Core 7.10.3 and 7.11.0. A path the API user may not read, or that lies under a directory it may not read, fails the task with the server’s 403 fs_access_denied_error, which names the access right denied; the message ends with the hint that the file system’s permissions deny the API user this access.

  • The quota list ends with an empty page whose next link is an empty string (QUIRK-004); every page is read.

Examples

# These tasks carry no connection options. Set them once for the play with module_defaults for
# group/qumulo.cluster.qumulo, or in the QUMULO_* environment variables.
- name: Read the capacity and the quotas
  qumulo.cluster.filesystem_info:
    gather_subset: [capacity, quotas]
  register: fs

- name: List the paths that have a quota
  ansible.builtin.debug:
    msg: "{{ fs.filesystem.quotas | map(attribute='path') | list }}"

- name: Report the free space of the file system in terabytes
  qumulo.cluster.filesystem_info:
    gather_subset: [capacity]
  register: fs_capacity

- name: Show the free space
  ansible.builtin.debug:
    msg: "{{ (fs_capacity.filesystem.capacity.free_size_bytes / 1000 ** 4) | round(2) }} TB free"

- name: Find the quotas that are more than 90 percent used
  qumulo.cluster.filesystem_info:
    gather_subset: [quotas]
  register: fs_quotas

- name: Report the quotas that are more than 90 percent used
  ansible.builtin.debug:
    msg: "{{ item.path }} uses {{ item.capacity_usage }} of {{ item.limit }} bytes"
  loop: "{{ fs_quotas.filesystem.quotas }}"
  loop_control:
    label: "{{ item.path }}"
  when: item.capacity_usage > 0.9 * item.limit

- name: Read the owner and mode of the root directory
  qumulo.cluster.filesystem_info:
    gather_subset: [root]
  register: fs_root

- name: Show the root directory's owner and mode
  ansible.builtin.debug:
    msg: "{{ fs_root.filesystem.root.owner }} {{ fs_root.filesystem.root.mode }}"

# The file ids below are the cluster's own. Use one within the run that read it, and store it nowhere.
- name: Turn the paths of two directories into file ids, reading nothing else
  qumulo.cluster.filesystem_info:
    gather_subset: []
    find_files: [/data/projects, /data/scratch]
  register: ids

- name: Show the ids, or that a directory does not exist
  ansible.builtin.debug:
    msg: "{{ item.key }}: {{ item.value.id if item.value.found else 'not found' }}"
  loop: "{{ ids.filesystem.found_files | dict2items }}"
  loop_control:
    label: "{{ item.key }}"

- name: Turn the projects directory's id back into its path
  qumulo.cluster.filesystem_info:
    gather_subset: []
    find_files: ["{{ ids.filesystem.found_files['/data/projects'].id }}"]
  register: by_id
  when: ids.filesystem.found_files['/data/projects'].found

- name: Show the path that the id names
  ansible.builtin.debug:
    msg: "{{ by_id.filesystem.found_files[ids.filesystem.found_files['/data/projects'].id].path }}"
  when: by_id is not skipped

- name: Look up the projects directory
  qumulo.cluster.filesystem_info:
    gather_subset: []
    find_files: [/data/projects]
  register: projects

- name: Stop unless the projects directory exists
  # A path that does not exist is a miss, not an error, so the find passes and this task stops the play.
  ansible.builtin.assert:
    that: projects.filesystem.found_files['/data/projects'].found
    fail_msg: /data/projects does not exist on this cluster

- name: Look up the projects directory in a check run
  # A lookup only reads, so a check run answers as a real run does.
  qumulo.cluster.filesystem_info:
    gather_subset: []
    find_files: [/data/projects]
  check_mode: true
  register: projects_preview

- name: Show whether the check run found the projects directory
  ansible.builtin.debug:
    msg: "{{ projects_preview.filesystem.found_files['/data/projects'].found }}"

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

filesystem

dictionary

The gathered facts. Each key is present only when its subset was gathered.

Returned: always

capacity

dictionary

The file system’s sizes in bytes, one key for each field of /v1/file-system that ends in _bytes, such as total_size_bytes, free_size_bytes and portal_cache_size_bytes.

Returned: success

free_size_bytes

integer

The space not yet used, or null when the cluster reports none.

Returned: success

Sample: 60000000000000

total_size_bytes

integer

The file system’s usable size, or null when the cluster reports none.

Returned: success

Sample: 100000000000000

found_files

dictionary

Each term of find_files, under the term as given, with the file it names. A path given with a trailing slash is a key with its slash, and the path under it has none.

Each value holds the keys below.

Returned: when find_files is given

Sample: {"/data/projects": {"found": true, "id": "1003", "path": "/data/projects", "type": "FS_FILE_TYPE_DIRECTORY"}, "/data/removed": {"found": false, "id": null, "path": null, "type": null}}

found

boolean

Whether the term names a file on this cluster.

Returned: always

Sample: true

id

string

The file’s id, a string of decimal digits, or null when the term names no file.

The id holds only on this cluster and until it is rebuilt; see find_files.

Returned: always

Sample: "1003"

path

string

The file’s canonical path, without a trailing slash except for the root, /, or null when the term names no file.

Returned: always

Sample: "/data/projects"

type

string

The file’s type as the cluster names it, such as FS_FILE_TYPE_FILE or FS_FILE_TYPE_DIRECTORY, or null when the term names no file.

Returned: always

Sample: "FS_FILE_TYPE_DIRECTORY"

quotas

list / elements=dictionary

Every directory quota, in the option shape of qumulo.cluster.directory_quota, with capacity_usage in bytes.

Returned: success

capacity_usage

integer

The bytes the directory uses against the quota.

Returned: success

Sample: 4096

limit

integer

The quota in bytes.

Returned: success

Sample: 2199023255552

path

string

The directory’s path.

Returned: success

Sample: "/data/projects"

root

dictionary

The root directory, in the option shape of qumulo.cluster.directory.

Returned: success

Sample: {"group": "local:Users", "mode": "0777", "owner": "local:admin", "path": "/"}

group

string

The group as a trustee.

Returned: success

Sample: "local:Users"

mode

string

The POSIX mode, four octal digits.

Returned: success

Sample: "0777"

owner

string

The owner as a trustee.

Returned: success

Sample: "local:admin"

path

string

The directory’s path, always /.

Returned: success

Sample: "/"

term

string

The find_files term whose read failed.

Returned: when the read of a term fails

Sample: "/data/projects"

unavailable_subsets

dictionary

Each requested subset this cluster could not answer, with the reason.

Returned: when a subset was unavailable

Sample: {"capacity": "the node is UNCONFIGURED"}
