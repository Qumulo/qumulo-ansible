qumulo.cluster.nexus_connection module – Manage a Qumulo cluster’s connection to Qumulo’s Nexus service

Note

This module is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.nexus_connection.

New in qumulo.cluster 0.1.0

  • Synopsis

Synopsis

  • Sets whether the cluster connects to Nexus, where, how often, and which Nexus capabilities it allows.

  • Only the options that differ from the cluster are written, in one PATCH. Each option left unset keeps the cluster’s value.

  • Registering the cluster with Nexus is qumulo.cluster.nexus_registration‘s job.

Parameters

Parameter

Comments

api_host

string / required

Address or name of the Qumulo cluster’s REST API.

An IPv6 address is given bare, as fd00::5; the URL puts it in brackets.

If not set, the value of the QUMULO_API_HOST environment variable is used.

api_password

string

Password of api_username.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_PASSWORD environment variable is used.

api_port

integer

TCP port of the REST API.

If not set, the value of the QUMULO_API_PORT environment variable is used.

Default: 8000

api_token

string

An access token, sent in place of logging in.

An access token is bound to one cluster and does not survive a rebuild.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_TOKEN environment variable is used.

api_username

string

User that logs in with api_password.

If not set, the value of the QUMULO_API_USERNAME environment variable is used.

Default: "admin"

ca_path

path

PEM file of the certificate authority that signed the cluster’s certificate.

On Python 3.13 and later this must be a CA certificate, with basic constraints.

A bare self-signed leaf certificate cannot be pinned here on Python 3.13 and later; such a cluster is reached only with validate_certs=false.

If not set, the value of the QUMULO_CA_PATH environment variable is used.

expected_cluster_uuid

string

The UUID the cluster at api_host must have.

Before the first credentials are sent, the module reads the cluster’s UUID from GET /v1/node/state, which needs no login, and fails when it differs, so that no credentials are sent to the wrong cluster. On a mismatch the task fails with live_cluster_uuid and expected_cluster_uuid in its result.

An empty value disables this identity guard, and a module that logs in warns.

If not set, the value of the QUMULO_EXPECTED_CLUSTER_UUID environment variable is used.

nexus_capability_remote_support

boolean

Whether Qumulo Care may reach the cluster through Nexus for remote support.

Choices:

  • false

  • true

nexus_capability_sso

boolean

Whether users may sign in to the cluster through Nexus single sign-on.

Choices:

  • false

  • true

nexus_enabled

boolean

Whether the cluster connects to Nexus.

Turning it on needs cloud monitoring on (qumulo.cluster.monitoring_settings enabled), and the module fails before any write when it is off (QUIRK-015).

Turning cloud monitoring off turns this off too.

Choices:

  • false

  • true

nexus_host

string

Host of the Nexus service the cluster connects to.

nexus_interval

integer

Seconds between the cluster’s reports to Nexus.

nexus_port

integer

Port of that host.

request_timeout

integer

Seconds to wait for one HTTP response.

If not set, the value of the QUMULO_REQUEST_TIMEOUT environment variable is used.

Default: 60

retry_timeout

integer

Seconds to keep retrying a request that is safe to resend, after a lost connection or an HTTP 502, 503 or 504.

If not set, the value of the QUMULO_RETRY_TIMEOUT environment variable is used.

Default: 300

validate_certs

boolean

Verify the cluster’s TLS certificate.

If not set, the value of the QUMULO_VALIDATE_CERTS environment variable is used.

Choices:

  • false

  • true ← (default)

Attributes

Attribute

Support

Description

action_group

Action group: qumulo.cluster.qumulo

Use group/qumulo.cluster.qumulo in module_defaults to set the connection options for this module.

check_mode

Support: full

With cloud monitoring off, check mode predicts turning the connection on and warns, because an earlier qumulo.cluster.monitoring_settings task in the same check-mode run turned nothing on.

Can run in check mode and return a changed status prediction without modifying the cluster.

diff_mode

Support: full

Will return details on what has changed, or would change in check mode, when in diff mode.

idempotent

Support: full

When run twice in a row outside check mode with the same arguments, the second run reports no change.

This assumes that nothing else changed the cluster in between.

Notes

Note

  • API: GET and PATCH /v1/nexus/connection (If-Match); GET /v1/support/settings when the task turns the connection on.

  • A write that meets HTTP 412 is read and sent again, up to five sends in all.

Examples

# These tasks carry no connection options. Set them once for the play with module_defaults for
# group/qumulo.cluster.qumulo, or in the QUMULO_* environment variables.
# The Nexus connection needs cloud monitoring on, and the module fails before any write when it is off.
- name: Turn on cloud monitoring and connect the cluster to Nexus
  block:
    - name: Turn on cloud monitoring
      qumulo.cluster.monitoring_settings:
        enabled: true
        wait: true

    - name: Connect the cluster to Nexus
      qumulo.cluster.nexus_connection:
        nexus_enabled: true

- name: Report to Nexus every minute and allow remote support
  qumulo.cluster.nexus_connection:
    nexus_interval: 60
    nexus_capability_remote_support: true

- name: Connect to a Nexus service at another host
  qumulo.cluster.nexus_connection:
    nexus_host: nexus.example.com
    nexus_port: 443

- name: Preview allowing Nexus single sign-on
  qumulo.cluster.nexus_connection:
    nexus_capability_sso: true
  check_mode: true
  diff: true
  register: nexus_preview

- name: Show the connection settings the change would leave
  ansible.builtin.debug:
    var: nexus_preview.nexus_connection

- name: Let users sign in through Nexus single sign-on
  qumulo.cluster.nexus_connection:
    nexus_capability_sso: true

- name: Stop Qumulo Care reaching the cluster through Nexus
  qumulo.cluster.nexus_connection:
    nexus_capability_remote_support: false

- name: Disconnect the cluster from Nexus
  qumulo.cluster.nexus_connection:
    nexus_enabled: false

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

expected

dictionary

The values the module wrote for the options that did not converge.

Returned: when the cluster reads back different values from the ones written

Sample: {"nexus_interval": 60}

maybe_applied

boolean

true when a write was sent, its answer was lost and reading back did not confirm it; the task fails with changed set.

Returned: on such a failure

Sample: true

nexus_connection

dictionary

The Nexus connection settings after the task, or in check mode the settings the task would leave.

Returned: always

Sample: {"nexus_capability_remote_support": true, "nexus_capability_sso": false, "nexus_enabled": true, "nexus_host": "api.nexus.qumulo.com", "nexus_interval": 30, "nexus_port": 443}

boolean

Whether Qumulo Care may reach the cluster through Nexus for remote support.

Returned: success

nexus_capability_sso

Returned: success

boolean

Returned: success

string
