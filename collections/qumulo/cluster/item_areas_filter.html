qumulo.cluster.item_areas filter – The keys inside list items that put a declared variable in an area

Note

This filter plugin is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.item_areas.

New in qumulo.cluster 0.1.0

  • Synopsis

  • Input

  • Keyword parameters

  • Examples

  • Return Value

Synopsis

  • Finds the keys that the matchers name inside the items of list variables, and gives each with its area, as the ownership check of the cluster_baseline role lists what the inventory declares.

  • A matcher such as qumulo_tenants[].networks[].floating_ip_ranges starts at a variable, and each [] stands for each item of the list before it.

  • A key counts when an item has it with any value but null, [] included. An unset variable, an item that is not a dict, and a value before [] that is not a list declare nothing.

  • Each key is named with each item’s id, else its name, share_name or export_path, else its index, as in qumulo_tenants[finance].networks[2].floating_ip_ranges, and is given once for each area.

Input

This describes the input of the filter, the value before | qumulo.cluster.item_areas.

Parameter

Comments

Input

dictionary / required

The matchers, a dict of each area to a list of matchers, as cluster_baseline_item_areas gives them.

Keyword parameters

This describes keyword parameters of the filter. These are the values key1=value1, key2=value2 and so on in the following example: input | qumulo.cluster.item_areas(key1=value1, key2=value2, ...)

Parameter

Comments

qumulo_tenants

list / elements=dictionary

The value of qumulo_tenants, or null when it is unset.

Each other keyword names another variable the matchers start at in the same way.

Examples

- name: List the areas a tenant's keys are in
  ansible.builtin.debug:
    msg: >-
      {{ {'network': ['qumulo_tenants[].networks'], 'smb': ['qumulo_tenants[].smb_settings']}
         | qumulo.cluster.item_areas(qumulo_tenants=qumulo_tenants | default(none)) }}

- name: Fail when a tenant declares networks in an area Terraform owns
  ansible.builtin.assert:
    that: >-
      cluster_baseline_item_areas | qumulo.cluster.item_areas(qumulo_tenants=qumulo_tenants | default(none))
      | selectattr('area', 'in', qumulo_terraform_owned_areas | default([])) | list | length == 0
    fail_msg: A tenant declares keys in an area that Terraform owns.

Return Value

Key

Description

Return value

list / elements=dictionary

Each key found, in matcher order and then item order.

Returned: always

area

string

The area of the matcher that found the key.

Returned: success

Sample: "network.floating_ips"

variable

string

The key, named by the variable and each item it is in.

Returned: success

Sample: "qumulo_tenants[finance].networks[2].floating_ip_ranges"
