qumulo.cluster.edge_rebuild role – Rebuild a Qumulo unprotected edge, draining it first, and bring the new edge back to its baseline

Note

This role is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.edge_rebuild.

Entry point main – Rebuild a Qumulo unprotected edge, draining it first, and bring the new edge back to its baseline

New in qumulo.cluster 0.1.0

Synopsis

  • A rebuilt edge always has a new UUID (G-UUID); everything keyed on the old one is cleaned up or replayed. The role replays the inventory, never the state of the edge it destroys.

  • Whatever edge_rebuild_phase is, the role first checks the inventory against the argument specification of the cluster_baseline role, which refuses a key that a variable’s options do not list, such as a misspelt one, with Validation of arguments failed:. That check comes before any contact with an edge, so a rebuild in one run is refused before it drains anything.

  • With edge_rebuild_phase=predestroy, on the old edge, it checks the UUID with qumulo.cluster.cluster_guard; writes the info modules’ facts to captured-<UTC>.yml; fails with qumulo.cluster.edge_rebuild_preflight when the edge holds state the inventory does not declare, declares absent, or the replay cannot create again, data outside the portal’s spoke roots among it, reading each replication peer’s record of the relationships the inventory declares with the edge as their source or target, through the peer’s inventory host; drains every portal the edge holds with the portal_pair role, through the inventory host in qumulo_hubs whose qumulo_cluster_uuid is its hub’s, declared or not, and deletes it on both sides; leaves the domain; removes the Nexus registration and, with qumulo_nexus_api_token, retires the UUID in Nexus; and writes predestroy-<UTC>.yml, which records what was drained and deleted and says the edge is safe to destroy. A check run writes no record.

  • With edge_rebuild_phase=replay, on the new edge, it connects as admin with edge_rebuild_admin_password; checks that the edge is UNCONFIGURED, or newly formed and empty, with qumulo.cluster.cluster_guard in mode rebuilt, and that it is not the cluster qumulo_cluster_uuid names; deletes the hub’s record of the old UUID; forms the edge with qumulo.cluster.unprotected_edge_create when it is UNCONFIGURED; switches qumulo_cluster_uuid to the new UUID and adds the old one to qumulo_previous_cluster_uuids; retires the old UUID in Nexus with qumulo_nexus_api_token; runs the cluster_baseline role, which pairs the edge with its hub again and holds each replication relationship whose replica may be the only copy of the edge’s data; and writes rebuild-<UTC>.yml with the host_vars patch and what is left to hands, each relationship into the edge waiting for the second pass, each lock key the old edge held (or that its key store could not be read) and each snapshot policy applied without its lock key among it. It refuses qumulo_replication_release and qumulo_replication_restore first.

  • With edge_rebuild_phase=all, it runs predestroy, then edge_rebuild_reinstall_tasks, then replay, and checks what the replay needs from the inventory before the predestroy changes anything.

  • The replay needs -e qumulo_rebuild=true, edge_rebuild_eula_accepted, the admin password, the old edge’s qumulo_cluster_uuid, qumulo_cluster_name, both keys of qumulo_factory_defaults, a qumulo_portal.hub in the qumulo_hubs group with qumulo_cluster_uuid, qumulo_portal_hosts on the edge and on the hub, no quota or snapshot policy under a spoke root, no path with both a mode in qumulo_directories and an ACL in qumulo_file_acls (G-FS-ACL-MODE), and with qumulo_ad a record that the old edge left the domain with credentials, or edge_rebuild_old_edge_destroyed. An edge formed by hand needs qumulo_new_cluster_uuid, its new UUID.

  • A rebuilt edge forms unlicensed with the smaller of its platform’s capacity and 1 TB (G-EDGE-FLOOR), and provisioning never shrinks (G-CLAMP-SHRINK). The role refuses a declared qumulo_capacity.clamp more than its rounding tolerance below min(1 TB, edge_cache_resize_floor_bytes), whatever qumulo_capacity.license says, and qumulo_capacity.license=none beside a license document, as the license step does. Both refusals come before the drain in a rebuild in one run, and before the formation in the replay phase of one in two runs.

  • Without qumulo_new_cluster_uuid, the replay takes the edge’s qumulo_cluster_uuid as the new UUID when it is not the old one, as when a Terraform edge resource that the qumulo.cluster.terraform inventory plugin reads is replaced; with edge_rebuild_phase=all it reads the inventory again after the reinstall tasks for that. A replay on its own whose inventory UUID no predestroy record names takes the old UUID from the newest predestroy record that says it was safe to destroy, of a UUID no rebuild report has replaced. The report then has no host_vars patch.

  • A rebuilt edge’s key store is empty, so the role refuses, before the predestroy changes anything, in either form of the rebuild, an inventory whose qumulo_snapshot_policies declares a lock_key, unless -e qumulo_allow_deferred_policy_lock_keys=true is given; a value in the inventory has no effect. With it, the replay applies those policies without their keys and hands them off; register the keys, then run the baseline again.

  • Under --check, predestroy predicts its changes, drains nothing and writes no record, a rebuild in one run stops before the reinstall, and a replay onto an UNCONFIGURED node stops after predicting the formation.

  • Connects through the play’s module_defaults for group/qumulo.cluster.qumulo, as playbooks/edge_predestroy.yml and playbooks/edge_rebuild.yml set them.

Parameters

Parameter

Comments

edge_cache_resize_floor_bytes

integer

The capacity a rebuilt edge provisions at formation, if its platform is larger (G-EDGE-FLOOR), as the qumulo.cluster.edge_cache_resize role reads it. The refusal of a declared clamp below the floor follows it, bounded by 1 TB.

Default: 1000000000000

edge_rebuild_acknowledge

list / elements=string

Areas of state the replay cannot create again to rebuild without, from network, kmip, replication, the replication relationships the inventory does not declare present, s3_keys, access_tokens and local_data, data outside the portal’s spoke roots, which no drain moves to the hub, and the target directories of declared relationships the replay cannot rebuild from their sources. The report lists what each needs by hand.

Default: []

edge_rebuild_ad_leave

boolean

Leave the domain in predestroy. Only with qumulo_ad.join_user and qumulo_ad.join_password does the leave delete the computer account, and only then does the record say the old edge left, which a replay with qumulo_ad needs.

Defaults to whether qumulo_ad is set.

Choices:

  • false

  • true

edge_rebuild_admin_password

string

The password of the new edge’s admin user, which the replay forms the edge with and connects as, until the baseline changes it. Defaults to qumulo_api_password.

The replay never connects with qumulo_api_token or another qumulo_api_username, which belong to the old edge.

edge_rebuild_allow_data_loss

boolean

When the drain fails, force the deletion of the portal on both sides, losing the edge’s writes that the hub has not received; and delete without a drain a portal whose hub no inventory host names. In the replay, delete the hub’s DISCONNECTED record of an old edge no predestroy record shows drained.

Choices:

  • false ← (default)

  • true

edge_rebuild_artifact_dir

path

Where each edge’s records go, under a directory named after its inventory host.

Defaults to an artifacts directory beside the inventory source that defines the host, never inside it.

edge_rebuild_drain_timeout

integer

Seconds to wait for the drain, and for each portal record to go.

Default: 3600

edge_rebuild_eula_accepted

boolean

Accept Qumulo’s end user license agreement, which forming the edge needs. Required for the replay.

Choices:

  • false

  • true

edge_rebuild_ignore_drift

boolean

Rebuild although the edge holds tenants, tenant networks, shares, exports, quotas, policies, users, groups or portal roots the inventory does not declare, or declares absent. They are lost. It also accepts a tenant 1 that the rebuilt edge gains, when the old edge lacks one, and a network the old edge holds in no tenant that the rebuilt edge puts in tenant 1. It does not waive an inventory the replay would refuse. State the replay cannot create again still needs edge_rebuild_acknowledge.

Choices:

  • false ← (default)

  • true

edge_rebuild_nexus_deregister

boolean

Remove the edge’s Nexus registration in predestroy, and with qumulo_nexus_api_token retire its UUID.

Choices:

  • false

  • true ← (default)

edge_rebuild_old_edge_destroyed

boolean

Declares that the old edge is gone, for a replay with qumulo_ad that finds no predestroy record of a domain leave. A join under the old name resets the computer account a live old edge still uses.

Choices:

  • false ← (default)

  • true

edge_rebuild_phase

string / required

Which part of the rebuild to run.

Choices:

  • "predestroy"

  • "replay"

  • "all"

edge_rebuild_reinstall_tasks

path

The absolute path of a tasks file that reinstalls the edge, run between the phases with edge_rebuild_phase=all. It runs on the edge’s host, and when it returns the node must answer at qumulo_api_host, UNCONFIGURED or newly formed.

edge_rebuild_validate_factory_certs

boolean

With false, the replay connects to the new edge without verifying the factory certificate it serves, which nothing can verify (G-FACTORY-TLS), until the baseline installs qumulo_ssl and verifies the edge from then on with qumulo_ssl.ca_path_after, which it then needs. It applies to the new edge only; the hub stays verified, and the certificate step turns verification back on. It is a variable of the edge host, as host_vars set it.

Choices:

  • false

  • true ← (default)
