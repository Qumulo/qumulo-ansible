qumulo.cluster.snapshot module – Take a snapshot of a directory on a Qumulo cluster

Note

This module is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.snapshot.

New in qumulo.cluster 0.1.0

Synopsis

  • Takes an on-demand snapshot of one directory, with an optional name and expiration.

  • Every run takes another snapshot and reports a change (G-ACTIONS), unless reuse_existing finds one to return.

  • The cluster prefixes each snapshot’s name with an id it generates, <id>_<name>, so the name the task gives never identifies a snapshot by itself. With reuse_existing, the module looks for a snapshot of the directory whose name is name after its id.

Parameters

Parameter

Comments

api_host

string / required

Address or name of the Qumulo cluster’s REST API.

An IPv6 address is given bare, as fd00::5; the URL puts it in brackets.

If not set, the value of the QUMULO_API_HOST environment variable is used.

api_password

string

Password of api_username.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_PASSWORD environment variable is used.

api_port

integer

TCP port of the REST API.

If not set, the value of the QUMULO_API_PORT environment variable is used.

Default: 8000

api_token

string

An access token, sent in place of logging in.

An access token is bound to one cluster and does not survive a rebuild.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_TOKEN environment variable is used.

api_username

string

User that logs in with api_password.

If not set, the value of the QUMULO_API_USERNAME environment variable is used.

Default: "admin"

ca_path

path

PEM file of the certificate authority that signed the cluster’s certificate.

On Python 3.13 and later this must be a CA certificate, with basic constraints.

A bare self-signed leaf certificate cannot be pinned here on Python 3.13 and later; such a cluster is reached only with validate_certs=false.

If not set, the value of the QUMULO_CA_PATH environment variable is used.

expected_cluster_uuid

string

The UUID the cluster at api_host must have.

Before the first credentials are sent, the module reads the cluster’s UUID from GET /v1/node/state, which needs no login, and fails when it differs, so that no credentials are sent to the wrong cluster. On a mismatch the task fails with live_cluster_uuid and expected_cluster_uuid in its result.

An empty value disables this identity guard, and a module that logs in warns.

If not set, the value of the QUMULO_EXPECTED_CLUSTER_UUID environment variable is used.

expiration_time_to_live

string

How long the snapshot is kept, as a whole number and a unit, such as 90minutes, 12hours, 7days, 2weeks or 6months. The unit may be singular, and months are calendar months.

The time is counted from when the module runs on the controller.

never, or leaving it unset, keeps the snapshot until it is deleted.

name

string

The name the snapshot carries after its id, such as before-upgrade, without /. Left unset, the cluster names it OnDemand.

The id and the name together are at most 128 characters.

path

string / required

Absolute path of the directory to snapshot, such as /data/projects. A trailing slash is ignored.

The cluster takes no snapshot of a directory on or under a portal spoke root (G-SPOKE-PATHS); the module refuses it first, even in check mode.

request_timeout

integer

Seconds to wait for one HTTP response.

If not set, the value of the QUMULO_REQUEST_TIMEOUT environment variable is used.

Default: 60

retry_timeout

integer

Seconds to keep retrying a request that is safe to resend, after a lost connection or an HTTP 502, 503 or 504.

If not set, the value of the QUMULO_RETRY_TIMEOUT environment variable is used.

Default: 300

reuse_existing

boolean

Take no snapshot when one of path named name exists and is not being deleted, and return the newest such snapshot instead. Needs name.

Its expiration is left as it is, whatever expiration_time_to_live says.

Choices:

  • false ← (default)

  • true

validate_certs

boolean

Verify the cluster’s TLS certificate.

If not set, the value of the QUMULO_VALIDATE_CERTS environment variable is used.

Choices:

  • false

  • true ← (default)

Attributes

Attribute

Support

Description

action_group

Action group: qumulo.cluster.qumulo

Use group/qumulo.cluster.qumulo in module_defaults to set the connection options for this module.

check_mode

Support: full

Predicts the snapshot, with the expiration it would get; the id is known only once it is taken.

Can run in check mode and return a changed status prediction without modifying the cluster.

diff_mode

Support: full

Will return details on what has changed, or would change in check mode, when in diff mode.

idempotent

Support: partial

Taking a snapshot is a one-shot action. With reuse_existing and name, a second run finds the first run’s snapshot and takes none.

When run twice in a row outside check mode with the same arguments, the second run reports no change.

This assumes that nothing else changed the cluster in between.

Notes

Note

  • API: GET /v1/files/{path}/info/attributes; GET /v2/portal/spokes/; with name, GET /v4/snapshots/status/; POST /v3/snapshots/.

  • If the connection is lost after the snapshot was requested, the module never requests it again. With name it lists the directory’s snapshots to find the one the request took; without, it fails, saying a snapshot may have been taken.

  • Registers: G-ACTIONS, G-SPOKE-PATHS.

Examples

# These tasks carry no connection options. Set them once for the play with module_defaults for
# group/qumulo.cluster.qumulo, or in the QUMULO_* environment variables.
- name: Snapshot the project tree before an upgrade, once however often the play reruns
  qumulo.cluster.snapshot:
    path: /data/projects
    name: before-upgrade-7-11
    expiration_time_to_live: 2weeks
    reuse_existing: true
  register: before_upgrade

- name: Show the snapshot's id and name
  ansible.builtin.debug:
    msg: "{{ before_upgrade.snapshot.id }}: {{ before_upgrade.snapshot.name }}"

- name: Take a snapshot of the project tree that is kept until it is deleted
  # Every run takes another snapshot and reports a change.
  qumulo.cluster.snapshot:
    path: /data/projects
    name: audit-hold

- name: Take an unnamed snapshot kept for 90 days
  # The cluster names it OnDemand after its id.
  qumulo.cluster.snapshot:
    path: /data/projects
    expiration_time_to_live: 90days

- name: Preview a snapshot kept for a day
  qumulo.cluster.snapshot:
    path: /data/projects
    expiration_time_to_live: 1day
  check_mode: true
  diff: true
  register: snapshot_preview

- name: Show when it would expire
  ansible.builtin.debug:
    msg: "it would expire at {{ snapshot_preview.snapshot.expiration }}"
  when: snapshot_preview.changed

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

maybe_applied

boolean

True when the snapshot was requested and the connection was lost before the module could confirm that the cluster took it.

Returned: on such a failure

Sample: true

notes

list / elements=string

What the module noticed, such as a snapshot it found by listing after the connection was lost, or a directory that does not exist yet in check mode.

Returned: when there is something to note

Sample: ["write reconciled after a lost connection"]

snapshot

dictionary

The snapshot taken, or found with reuse_existing; in check mode, the one that would be taken.

Returned: always

expiration

string

When the snapshot expires, in RFC 3339; an empty string for never.

Returned: success

Sample: "2026-11-16T02:44:35Z"

id

integer

The snapshot’s id; absent in check mode before it is taken.

Returned: success

Sample: 12

name

string

The snapshot’s name, its id and the name the task gave; in check mode, the name the task gave, or OnDemand.

Returned: success

Sample: "12_before-upgrade-7-11"

path

string

The directory, without a trailing slash.

Returned: success

Sample: "/data/projects"

timestamp

string

When the snapshot was taken; absent in check mode.

Returned: success

Sample: "2026-11-02T02:44:35.267716486Z"
