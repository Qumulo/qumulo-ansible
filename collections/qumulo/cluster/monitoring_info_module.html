qumulo.cluster.monitoring_info module – Read a Qumulo cluster’s monitoring, Nexus, audit and encryption settings and status

Note

This module is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.monitoring_info.

New in qumulo.cluster 0.1.0

  • Synopsis

  • Parameters

  • Attributes

  • Notes

  • Return Values

Synopsis

  • Gathers the cloud monitoring settings and each node’s monitoring status, the Nexus connection and registration, the audit log destinations, and the encryption key store’s status, and changes nothing.

  • The settings and nexus_connection subsets have the option shape of qumulo.cluster.monitoring_settings and qumulo.cluster.nexus_connection, so they can be fed back to those modules.

  • No subset returns a secret. A pending Nexus join key, which the cluster returns in cleartext, is left out, and the support VPN keys are never read.

  • On a node that is not yet part of a cluster (state UNCONFIGURED) no login is possible, so every subset is listed in unavailable_subsets, and the module warns.

Parameters

Parameter

Comments

api_host

string / required

Address or name of the Qumulo cluster’s REST API.

An IPv6 address is given bare, as fd00::5; the URL puts it in brackets.

If not set, the value of the QUMULO_API_HOST environment variable is used.

api_password

string

Password of api_username.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_PASSWORD environment variable is used.

api_port

integer

TCP port of the REST API.

If not set, the value of the QUMULO_API_PORT environment variable is used.

Default: 8000

api_token

string

An access token, sent in place of logging in.

An access token is bound to one cluster and does not survive a rebuild.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_TOKEN environment variable is used.

api_username

string

User that logs in with api_password.

If not set, the value of the QUMULO_API_USERNAME environment variable is used.

Default: "admin"

ca_path

path

PEM file of the certificate authority that signed the cluster’s certificate.

On Python 3.13 and later this must be a CA certificate, with basic constraints.

A bare self-signed leaf certificate cannot be pinned here on Python 3.13 and later; such a cluster is reached only with validate_certs=false.

If not set, the value of the QUMULO_CA_PATH environment variable is used.

expected_cluster_uuid

string

The UUID the cluster at api_host must have.

Before the first credentials are sent, the module reads the cluster’s UUID from GET /v1/node/state, which needs no login, and fails when it differs, so that no credentials are sent to the wrong cluster. On a mismatch the task fails with live_cluster_uuid and expected_cluster_uuid in its result.

An empty value disables this identity guard, and a module that logs in warns.

If not set, the value of the QUMULO_EXPECTED_CLUSTER_UUID environment variable is used.

gather_subset

list / elements=string

The subsets of facts to gather. all gathers every subset.

settings is the cloud monitoring settings, status each node’s monitoring status, nexus_connection and nexus_registration the Nexus connection and registration, audit the syslog and cloudwatch audit log destinations, and encryption the encryption key store’s status.

Choices:

  • "all" ← (default)

  • "settings"

  • "status"

  • "nexus_connection"

  • "nexus_registration"

  • "audit"

  • "encryption"

Default: ["all"]

request_timeout

integer

Seconds to wait for one HTTP response.

If not set, the value of the QUMULO_REQUEST_TIMEOUT environment variable is used.

Default: 60

retry_timeout

integer

Seconds to keep retrying a request that is safe to resend, after a lost connection or an HTTP 502, 503 or 504.

If not set, the value of the QUMULO_RETRY_TIMEOUT environment variable is used.

Default: 300

validate_certs

boolean

Verify the cluster’s TLS certificate.

If not set, the value of the QUMULO_VALIDATE_CERTS environment variable is used.

Choices:

  • false

  • true ← (default)

Notes

Note

  • API: settings GET /v1/support/settings; status GET /v1/support/status/; nexus_connection GET /v1/nexus/connection; nexus_registration GET /v1/nexus/registration; audit GET /v1/audit/syslog/config, /v1/audit/syslog/status, /v1/audit/cloudwatch/config and /v1/audit/cloudwatch/status; encryption GET /v2/encryption/key-store/status.

  • A route this cluster does not offer (HTTP 404, 405, 406 or 501) makes its subset unavailable. A cluster that cannot send audit logs to CloudWatch reports cloudwatch as null. Any other error, such as a missing RBAC privilege, fails the module.

  • The license is qumulo.cluster.cluster_info‘s license subset.

  • audit reports only the destinations named syslog and cloudwatch, which the v1 routes it reads cover, and no local destination; qumulo.cluster.capture_info‘s audit area reads every destination (G-MON-AUDIT-INFO).

Examples

# These tasks carry no connection options, except where a task names another cluster. Set them once for the play
# with module_defaults for group/qumulo.cluster.qumulo, or in the QUMULO_* environment variables.
- name: Read every monitoring, Nexus, audit and encryption fact
  qumulo.cluster.monitoring_info:
  register: monitoring

- name: Show the cloud monitoring settings
  ansible.builtin.debug:
    var: monitoring.monitoring.settings

- name: Stop unless the cluster is registered with Nexus
  block:
    - name: Read the Nexus registration
      qumulo.cluster.monitoring_info:
        gather_subset: [nexus_registration]
      register: nexus_state

    - name: Assert that the cluster is registered
      ansible.builtin.assert:
        that: nexus_state.monitoring.nexus_registration.registration_status == 'REGISTERED'
        fail_msg: The cluster is not registered with Nexus.

- name: Fail when a node does not report monitoring as connected
  block:
    - name: Read each node's monitoring status
      qumulo.cluster.monitoring_info:
        gather_subset: [status]
      register: node_status

    - name: Assert that every node is connected
      ansible.builtin.assert:
        that: node_status.monitoring.status | map(attribute='monitoring') | unique | list == ['CONNECTED']

# Destinations with other names, which qumulo.cluster.audit_destination manages, are in qumulo.cluster.capture_info's
# audit area (G-MON-AUDIT-INFO).
- name: Read the syslog and CloudWatch audit destinations and their connection status
  qumulo.cluster.monitoring_info:
    gather_subset: [audit]
  register: audit_state

# A cluster that does not offer a route leaves its subset out of the facts and names it in unavailable_subsets.
- name: Read the encryption key store, if this cluster offers it
  qumulo.cluster.monitoring_info:
    gather_subset: [encryption]
  register: encryption_state

- name: Show when the key was last rotated
  ansible.builtin.debug:
    var: encryption_state.monitoring.encryption.last_key_rotation_time
  when: "'encryption' not in (encryption_state.unavailable_subsets | default({}))"

# The settings subset has the option shape of monitoring_settings, so it can be applied to another cluster.
# Both clusters must accept the credentials the play sets, since an api_token is bound to one cluster. api_host is a
# task argument here: a task-level module_defaults entry for the group would replace the play's credentials.
- name: Copy one cluster's monitoring settings to another
  block:
    - name: Read the source cluster's monitoring settings
      qumulo.cluster.monitoring_info:
        api_host: edge01.example.com
        gather_subset: [settings]
      register: source_monitoring

    # Name each field to copy; the proxy and VPN fields copy the same way.
    - name: Apply them to the other cluster
      qumulo.cluster.monitoring_settings:
        api_host: edge02.example.com
        enabled: "{{ source_monitoring.monitoring.settings.enabled }}"
        mq_host: "{{ source_monitoring.monitoring.settings.mq_host }}"
        mq_port: "{{ source_monitoring.monitoring.settings.mq_port }}"
        period: "{{ source_monitoring.monitoring.settings.period }}"

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

monitoring

dictionary

The gathered facts. Each key is present only when its subset was gathered and available.

Returned: always

audit

dictionary

The syslog and cloudwatch audit log destinations, as the v1 routes return them, each with its connection status.

cloudwatch is null on a cluster that cannot send audit logs to CloudWatch.

Returned: success

Sample: {"cloudwatch": null, "syslog": {"enabled": false, "format": "csv", "server_address": "", "server_port": 0, "status": {"connection_status": "AUDIT_LOG_DISABLED"}}}

cloudwatch

dictionary

The CloudWatch destination’s configuration, with its connection status; null when the cluster cannot send audit logs to CloudWatch.

Returned: success

syslog

dictionary

The syslog destination’s configuration, with its connection status.

Returned: success

encryption

dictionary

The encryption key store’s type and status, as the cluster reports them.

Returned: success

Sample: {"last_key_rotation_time": "2026-10-31T02:40:19Z", "status": "Encrypted", "type": "Local"}

nexus_connection

dictionary

The Nexus connection settings, as qumulo.cluster.nexus_connection takes them.

Returned: success

Sample: {"nexus_enabled": true, "nexus_host": "api.nexus.qumulo.com", "nexus_interval": 30, "nexus_port": 443}

nexus_registration

dictionary

The Nexus registration status and when the cluster’s Nexus secret was created; no other field is passed on.

Returned: success

registration_status

string

The registration status, such as NONE, PENDING_REGISTRATION or REGISTERED.

Returned: success

Sample: "REGISTERED"

secret_created_at

string

When the cluster’s Nexus secret was created.

Returned: success

Sample: "2026-10-31T02:00:00Z"

settings

dictionary

The cloud monitoring settings, as qumulo.cluster.monitoring_settings takes them.

Returned: success

Sample: {"enabled": true, "mq_host": "monitor.example.com", "mq_port": 443, "period": 60, "vpn_enabled": false}

status

list / elements=dictionary

Each node’s monitoring, file upload and VPN status.

Returned: success

Sample: [{"file_upload": "DISABLED", "monitoring": "CONNECTED", "node_id": 1, "vpn_connection": "DISABLED"}]

file_upload

string

The node’s file upload status.

Returned: success

Sample: "DISABLED"

monitoring

string

The node’s monitoring connection status, such as CONNECTED, DISABLED or ERROR.

Returned: success

Sample: "CONNECTED"

node_id

integer

The node’s ID.

Returned: success

Sample: 1

vpn_connection

string

The node’s remote-support VPN status.

Returned: success

Sample: "DISABLED"

unavailable_subsets

dictionary

Each requested subset this cluster could not answer, with the reason.

Returned: when a subset was unavailable

Sample: {"encryption": "GET /v2/encryption/key-store/status failed: HTTP 404 ..."}
