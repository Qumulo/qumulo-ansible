qumulo.cluster.portal_eviction_settings module – Manage the free-capacity threshold at which a cluster evicts cached spoke data

Note

This module is part of the qumulo.cluster collection (version 0.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install qumulo.cluster.

To use it in a playbook, specify: qumulo.cluster.portal_eviction_settings.

New in qumulo.cluster 0.1.0

  • Synopsis

  • Parameters

  • Attributes

Synopsis

  • Manages the cluster’s eviction setting, the fraction of the file system’s capacity that the cluster keeps free by evicting data it caches for its spoke portals. A cluster has one such setting, so nothing selects it.

  • The setting exists on every cluster and takes effect on clusters that host spoke portals.

Parameters

Parameter

Comments

api_host

string / required

Address or name of the Qumulo cluster’s REST API.

An IPv6 address is given bare, as fd00::5; the URL puts it in brackets.

If not set, the value of the QUMULO_API_HOST environment variable is used.

api_password

string

Password of api_username.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_PASSWORD environment variable is used.

api_port

integer

TCP port of the REST API.

If not set, the value of the QUMULO_API_PORT environment variable is used.

Default: 8000

api_token

string

An access token, sent in place of logging in.

An access token is bound to one cluster and does not survive a rebuild.

Set exactly one of api_password and api_token. An empty string counts as unset.

If not set, the value of the QUMULO_API_TOKEN environment variable is used.

api_username

string

User that logs in with api_password.

If not set, the value of the QUMULO_API_USERNAME environment variable is used.

Default: "admin"

ca_path

path

PEM file of the certificate authority that signed the cluster’s certificate.

On Python 3.13 and later this must be a CA certificate, with basic constraints.

A bare self-signed leaf certificate cannot be pinned here on Python 3.13 and later; such a cluster is reached only with validate_certs=false.

If not set, the value of the QUMULO_CA_PATH environment variable is used.

expected_cluster_uuid

string

The UUID the cluster at api_host must have.

Before the first credentials are sent, the module reads the cluster’s UUID from GET /v1/node/state, which needs no login, and fails when it differs, so that no credentials are sent to the wrong cluster. On a mismatch the task fails with live_cluster_uuid and expected_cluster_uuid in its result.

An empty value disables this identity guard, and a module that logs in warns.

If not set, the value of the QUMULO_EXPECTED_CLUSTER_UUID environment variable is used.

free_threshold

float / required

The fraction of capacity to keep free, from 0.0 to 1.0.

A value outside that range fails before any request is sent.

Values that differ by less than one millionth are treated as equal, so a value the server stores with a different float rounding is not reported as a change.

A newly formed cluster stores 0.05, not the 0.15 that Qumulo’s API documentation gives (QUIRK-009).

request_timeout

integer

Seconds to wait for one HTTP response.

If not set, the value of the QUMULO_REQUEST_TIMEOUT environment variable is used.

Default: 60

retry_timeout

integer

Seconds to keep retrying a request that is safe to resend, after a lost connection or an HTTP 502, 503 or 504.

If not set, the value of the QUMULO_RETRY_TIMEOUT environment variable is used.

Default: 300

validate_certs

boolean

Verify the cluster’s TLS certificate.

If not set, the value of the QUMULO_VALIDATE_CERTS environment variable is used.

Choices:

  • false

  • true ← (default)

Notes

Note

  • API: GET and PATCH /v1/portal/spokes/eviction-settings, with If-Match.

  • Like the portal hub and spoke routes, the eviction-settings route may return no ETag (G-PORTAL-ETAG); the PATCH is then sent without If-Match, and the last writer wins.

  • Registers: QUIRK-009, G-PORTAL-ETAG.

Examples

# These tasks carry no connection options. Set them once for the play with module_defaults for
# group/qumulo.cluster.qumulo, or in the QUMULO_* environment variables.
- name: Keep 15% of the edge's capacity free
  qumulo.cluster.portal_eviction_settings:
    free_threshold: 0.15

- name: Make the edge's cache smaller without a rebuild, by keeping a quarter of its capacity free
  # Evicting more needs neither a change to the capacity clamp (qumulo.cluster.capacity_clamp) nor a rebuild.
  qumulo.cluster.portal_eviction_settings:
    free_threshold: 0.25

- name: Preview the edge's eviction threshold from the inventory
  qumulo.cluster.portal_eviction_settings:
    free_threshold: "{{ qumulo_capacity.free_threshold }}"
  check_mode: true
  diff: true
  register: eviction_preview

- name: Show the threshold before and after
  ansible.builtin.debug:
    msg: >-
      {{ eviction_preview.diff.before.free_threshold }} -> {{ eviction_preview.eviction_settings.free_threshold }}
  when: eviction_preview.changed

- name: Set the threshold back to what a newly formed cluster stores
  qumulo.cluster.portal_eviction_settings:
    free_threshold: 0.05

- name: Read the eviction threshold that is in force
  qumulo.cluster.portal_info:
    gather_subset: [eviction]
  register: eviction_now

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

eviction_settings

dictionary

The settings after the task, or in check mode the settings the task would leave.

Returned: always

Sample: {"free_threshold": 0.15}

free_threshold

float

The fraction of capacity kept free.

Returned: success

expected

dictionary

The values the task wrote, for the options that did not converge.

Returned: when the read-back after a write differs from what was written; after a lost connection the task returns maybe_applied instead

Sample: {"free_threshold": 0.25}

maybe_applied

boolean

true when a write was sent and the connection was lost before the cluster answered, and reading the settings back did not confirm it. The task fails with changed true.

Returned: on a failure after such a write

Sample: true

notes

list / elements=string

What the module noticed, such as a write it confirmed by reading back after the connection was lost.

Returned: when there is something to note

Sample: ["write reconciled after a lost connection"]

observed

dictionary

What the cluster read back for the keys of expected.

Returned: when the read-back after a write differs from what was written; after a lost connection the task returns maybe_applied instead

Sample: {"free_threshold": 0.05}
